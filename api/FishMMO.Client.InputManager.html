A static utility class for managing game input, providing an abstraction layer over Unity's built-in Input and EventSystem. It allows for customizable virtual key and axis mappings, and controls mouse visibility and lock state.

ForcedMouseMode

Gets a value indicating whether the mouse cursor's visibility is currently being "forced" by an explicit call to ToggleMouseMode(bool) with forceMouseMode = true. When true, it suggests that the mouse mode might be locked in its current state, potentially overriding typical toggle behavior.

public static bool ForcedMouseMode { get; }

Property Value

bool

MouseMode

Gets or sets the current mouse mode. When true, the cursor is visible and unlocked. When false, the cursor is hidden and locked to the center of the game window. Setting this property also manages UI interaction based on the mouse mode.

public static bool MouseMode { get; set; }

ForceClickMouseButtonInCenterOfGameWindow()

In the Unity Editor, sends a simulated left mouse button click event to the center of the Game window. This can help ensure that the Game window gains focus and input is properly captured, especially after the mouse cursor is locked. This method has no effect in a built game.

ToggleMouseMode(bool)

Toggles the MouseMode between visible/unlocked and hidden/locked.

public static void ToggleMouseMode(bool forceMouseMode = false)

Parameters

forceMouseMode bool

If true, this call will set ForcedMouseMode to true, indicating that the mouse mode has been explicitly controlled. If false, it will clear the force flag. Note: The current implementation of ForcedMouseMode acts as a status flag, not a prevention mechanism for toggling.

Events

OnToggleMouseMode

An event that is invoked whenever the MouseMode property is toggled. Subscribers can listen to this event to react to changes in mouse visibility and lock state. The boolean parameter indicates the new state of MouseMode (true for visible/unlocked, false for hidden/locked).

public static event Action<bool> OnToggleMouseMode
