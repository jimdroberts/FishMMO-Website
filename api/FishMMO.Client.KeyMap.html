Struct KeyMap

Namespace

Assembly
Assembly-CSharp.dll

Represents a mapping between a custom virtual key name and its corresponding Unity UnityEngine.KeyCode. This struct provides a lightweight way to associate a user-friendly name with a specific physical key, and includes convenience methods to check the current state of the mapped key using Unity's Input system. Being a struct, it is a value type, which can offer minor performance benefits for small, frequently copied data, avoiding heap allocations.
