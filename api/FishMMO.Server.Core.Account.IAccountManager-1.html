Interface IAccountManager<TConnection>

Namespace
FishMMO.Server.Core.Account
Assembly
Assembly-CSharp.dll

Defines an interface for managing account and connection data, including encryption and SRP authentication state. This interface is generic and does not depend on any specific network implementation.
