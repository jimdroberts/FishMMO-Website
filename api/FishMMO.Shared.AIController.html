Controls AI navigation, state transitions, and behavior for NPCs using NavMeshAgent. Handles movement, enemy detection, leash logic, waypoints, and state management.

[RequireComponent(typeof(NavMeshAgent))]
public class AIController : CharacterBehaviour, IAIController, ICharacterBehaviour
