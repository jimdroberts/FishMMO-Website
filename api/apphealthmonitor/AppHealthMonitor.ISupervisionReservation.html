IDisposable.Dispose()

Remarks

Disposal releases the hold. It is safe, and required, to dispose a reservation whether or not Resume(Task) was called: a reservation released without a monitoring task simply lets the cycle carry on as it would have.

Gets whether the cycle this reservation belongs to can still supervise. False once the cycle or the daemon has been cancelled, at which point the caller must not launch.
