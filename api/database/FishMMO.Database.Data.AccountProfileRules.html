NormalizeDiscordUsername(string?)

Normalises a Discord username in either form Discord uses: a unique username (fishfan), or a name with its four-digit discriminator (FishFan#1234).

public static string? NormalizeDiscordUsername(string? input)

Parameters

input string

Returns

string

The normalised username, or null when it is not one.

Remarks

Trimmed, a leading @ dropped, and lowercased, because Discord matches both forms without regard to case.

A unique username is 2 to 32 lowercase letters, digits, underscores and periods, never two periods together. A name with a discriminator is the older form, whose names were freer — capitals, spaces, most of Unicode — so its name part is held only to its length and to what Discord never allowed in one: @, #, :, a code fence, control characters. The discriminator is exactly four digits.

Anything in neither form is refused rather than guessed at: the bot looks the name up exactly, and a DM sent to the wrong person is a verification code in a stranger's hands.

string

The normalised number, or null when it is not one.

Remarks

Spaces, hyphens, dots and parentheses are dropped, because that is how people write numbers. A leading 00 becomes +. A number without a country code is refused rather than guessed at: an SMS sent to the wrong country's number is a verification code in a stranger's hands.
