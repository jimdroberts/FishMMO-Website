Which verification codes an account is sent and asked for. One copy, shared by the game's login server and the Control Panel, so the two can never disagree about whether an account is let in.

Remarks

Any one channel verifies the account. A player may choose email, SMS and a Discord DM together; a code goes out on each, and whichever is entered first sets verified.

Verification is required when the server switches at least one channel on. A channel the player chose is asked for only when it is switched on and the account can receive it — SMS needs a phone number, Discord a username. When none of the player's choices qualifies, the account falls back to the first channel that does, in the order email, SMS, Discord: every account has an email address, so a player who picked a switched-off channel is still asked for a code rather than let in without one. Only an account that can receive no enabled channel at all is verified without a code, because no code could ever reach it.
