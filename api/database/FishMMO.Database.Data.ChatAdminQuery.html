Remarks

An object rather than a parameter list, for the reason AccountAdminQuery gives: eight optional filters as positional arguments is eight chances to transpose two of them at a call site where both are strings and nothing complains.

Every filter is optional and null means "do not narrow on this", with one exception that the service enforces rather than the type: see Text.

Remarks

Fifty, rather than the twenty-five an account search uses: a conversation is read in sequence, and a page that ends mid-exchange makes an operator page back and forth to reconstruct it.

MaxPageSize

The largest page the service will return, whatever is asked for.

public const int MaxPageSize = 200

Field Value

int

Remarks

The cap exists because the page size is the only part of this query a caller controls that has no upper bound of its own: every other filter can only narrow the result, while pageSize=1000000 asks the server to materialize the table.

HasNarrowingFilter

Whether this query narrows the search by something other than the message text.

public bool HasNarrowingFilter { get; }

Property Value

bool

Remarks

Deliberately does not count ToUtc or Channel. An upper time bound with no lower bound spans the whole history up to that instant, and a channel filter divides the table by a ten-valued column where the common values hold most of the rows — neither one turns a scan into anything smaller. Counting them would make the guard below feel satisfied while changing nothing about what the database does.

Text

Substring the message must contain, or null for no text filter.

public string? Text { get; set; }

Property Value

string

Remarks

A substring, unlike Query, which is a prefix precisely to stay index-serviceable. There is no prefix version of this filter that answers the question: a report says "they called me <slur>", and the slur is in the middle of the sentence. So this one accepts the leading wildcard it needs.

What it does not accept is being the ONLY filter. Supplied alone, it is refused with a validation error rather than silently bounded; see the search implementation for why refusing beats defaulting.
