Remarks

What a daemon judges expiry by, together with its own monotonic clock (DaemonCommandExpiry). It must never compare ExpiresUtc with its own wall clock: the stamp is the database's, so that comparison measured the skew between the two machines along with the time left, and a daemon five minutes ahead of the database refused every command it was given.
