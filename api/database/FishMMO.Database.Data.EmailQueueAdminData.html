Remarks

The body is deliberately absent. A verification email's body contains the verification link, and that link is a credential: anybody who can read it can verify the account it belongs to without ever holding the mailbox. The projection that fills this type does not name the body column, so the text never enters the panel process at all rather than being fetched and then carefully not serialized. What kind of mail it is — the only question the page asks of a message it cannot read — comes from Kind, which is the column the sender itself acts on, rather than from pattern-matching the subject line.
