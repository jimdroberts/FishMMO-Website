public enum ItemContainerType : byte

Remarks

The discriminator that replaced three parallel tables (character_inventory, character_equipment, character_bank). Those tables each had their own identity sequence, so inventory row 42 and equipment row 42 were two different items wearing the same number — which made Item.ID unusable as an identity and forced a second, process-local id alongside it. One table means one sequence, so an item id names exactly one item for as long as that item exists, whichever container it currently sits in.

The numeric values must match FishMMO.Shared.InventoryType exactly. They are two enums rather than one because this assembly cannot reference the Unity shared assembly, and the mapping between them is a cast. ItemContainerTypeParityTests pins the pairing; do not renumber either side.
