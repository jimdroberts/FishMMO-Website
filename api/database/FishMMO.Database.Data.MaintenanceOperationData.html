Remarks

The plan is rows, not a running procedure. Everything that acts on a server was written when the operation started; this record exists so an operator can see what was written, what the servers have done about it since, and — when it goes wrong — which target it went wrong on.

SecondsUntilDeadline

Seconds until DeadlineUtc, measured by the database clock when this was read; zero or negative once it has passed.

public double SecondsUntilDeadline { get; set; }

Property Value

double

Remarks

Measured by the clock the deadline was planned on and every server counts down against, never by the reader's. The panel used to subtract its own DateTime.UtcNow, so a panel host running slow showed a countdown with time still on it for servers that had already stopped. A reader that wants a live countdown anchors this on its own clock at the moment the reply arrived.
