Remarks

Carries ownership as the two columns the row stores rather than as a resolved owner, because this assembly cannot reference the shared types where that resolution lives. Callers turn the pair into a single answer with FishMMO.Shared.PlotOwner.TryFromColumns, which is also where a row holding both is caught.
