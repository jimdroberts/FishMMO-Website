Remarks

Self-describing on purpose: BaseFee and FeeRatePerDay travel with the row so what it costs to retrieve is answerable from this and the clock alone, with no template loaded and no server configuration consulted. A player quoted a price when their house was taken should be charged that price, not whatever the rates happen to be today.
