Remarks

WorldMsNow was computed inside the statement, against the same database clock that stamped BaseReferenceMs, so it does not carry the reader's clock skew. A reader that wants to keep the clock moving locally anchors WorldMsNow on its own monotonic clock the moment the reply arrives and advances it at Rate; it must not subtract its own wall clock from BaseReferenceMs.

When Exists is false, no scene server has seeded the row yet. Only DbNowMs is meaningful then; every other field is zero or null.
