Remarks

A WORLD TIMESTAMP is the calendar epoch (Unix seconds) plus the world milliseconds, written yyyy-MM-dd HH:mm:ss.fff in the invariant culture with no zone: it is UTC-style arithmetic on a calendar, not anybody's local time.

A CHANGE is a signed span: +1h30m, -90s, +2d3h4m5.25s, +250ms. Units d, h, m, s, ms, each at most once, largest first; a bare signed number is seconds. The sign is required, which is what tells a change from a timestamp.
