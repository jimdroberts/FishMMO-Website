Name

Unique account name, and the primary key.

public string Name { get; set; }

Property Value

string

Remarks

Stored lowercase. It used to be documented as preserving the casing the user registered with, and it does not: AccountService.PersistAsync inserts ToLowerInvariant(). Anything that displays this back to a player shows lowercase, and any code written on the belief that the original casing survives is wrong. NameLowercase is a generated column that exists so the unique index is case-insensitive regardless of what is inserted here.

NameLowercase

Case-insensitive lookup column for Name. Computed as LOWER(name) in the database and bound by a UNIQUE index so that two accounts cannot differ only in case. Application code must filter on this column (lowercased input) for all account-name lookups.

public string NameLowercase { get; set; }
