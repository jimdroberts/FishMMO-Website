Remarks

The security of the whole control plane is the shape of this row. It carries a verb from a closed enumeration and the name of an application the daemon already supervises. It carries no path, no arguments, no shell and nothing else the daemon executes. Somebody who can write to this table can restart a FishMMO process; they cannot make a game host run something new. Adding a column that changes that would turn a database password into remote code execution.

Claimed before it is executed. A daemon takes a command atomically and stamps itself on it, so two daemons cannot both act on one row, and a daemon that dies mid-command leaves a claimed row that can be seen rather than one that is silently done twice.

And it expires. A command nobody collected is abandoned rather than executed late: restarting a world server twenty minutes after an operator asked, once they have moved on and players are back on it, is worse than never doing it at all.
