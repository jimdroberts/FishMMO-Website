Remarks

The daemon writes this row and refreshes its heartbeat; nothing else does. A host that stops beating is the daemon going quiet, which is a different fault from an application going down — one needs somebody on that machine, the other does not.

The identity a command is addressed to. A daemon claims only commands naming its own host, so this string is also a scope boundary: get it wrong on two machines and they will both execute each other's work.
