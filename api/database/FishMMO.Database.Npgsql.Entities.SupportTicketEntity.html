Remarks

Filed from in-game and worked from the Control Panel. The player can follow it and reply; staff can reply, take notes the player never sees, and act.

No foreign keys on any of the account or character names here. The same reasoning as the audit log: a ticket describes something that happened, and deleting an account must not erase the report somebody filed about it — which is exactly the account most likely to be deleted. The names are copied in, and the character id is kept beside the name so the panel can still link to a character that has since been renamed.

Remarks

Tiers are access levels, not a parallel ladder: GameMaster (2) is the first tier and Admin (3) the second. A separate tier number would be one more thing for an operator to keep in step with the access level that actually decides what they can do, and a ticket escalated to "tier 2" that a tier-2 game master can still act on is a promotion that promotes nothing.

Stored as the byte value of AccessLevel, like accounts.access_level.
