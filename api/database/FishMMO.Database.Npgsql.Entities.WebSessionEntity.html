Remarks

Deliberately separate from AuthTokenEntity. That table's rows are game tokens issued by a LoginServer and carry a foreign key to login_servers; the Control Panel is not a login server, has no row to point at, and its sessions must not be accepted by a World or Scene server that validates game tokens.

Only the SHA-256 of the session identifier is stored, so a database read does not yield usable sessions.
