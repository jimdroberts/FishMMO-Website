Service interface for arena matches: reading the match a hosting scene server has just loaded, recording its progress and its result.

public interface IArenaMatchService

Remarks

Matches are created by TryFormArenaMatchAsync(long, string, int, int, int, int, DateTime, int, ArenaRatingSource, ArenaComposeOptions, CancellationToken), inside the transaction that takes the players out of the queue; nothing here creates one. The hosting scene server is not necessarily the one that formed the match, so everything it needs to run it is read back from these rows.
