Service interface for ranked arena seasons and per-season ratings.

public interface IArenaRatingService

Remarks

Ratings are keyed by season; a new season starts everyone over. The rating maths lives in the shared ArenaRating rules, not here — this service only stores the results and answers the leaderboard.
