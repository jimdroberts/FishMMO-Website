Beta codes and the accounts that redeemed them.

public interface IBetaCodeService

Remarks

Staff mint codes per program; a player redeems one at registration or later; while beta mode is on, the login gate asks HasAccessAsync(string, IReadOnlyCollection<string>, CancellationToken). The link an account gets is permanent. What ends access is revoking the code, never deleting anything.

Remarks

For registration, which must refuse a bad code BEFORE it creates the account: redeeming first would attach a use to an account name the insert may then find already taken — handing beta access to whoever owns that name. A check can race the redeem that follows it; the redeem is still the authority, and an account whose redeem loses that race exists without access and can redeem another code. An empty or null programs means any program. A malformed code is simply not redeemable.

HasAccessAsync(string, IReadOnlyCollection<string>, CancellationToken)

Whether the account holds a non-revoked code of any of the given programs.

Task<DatabaseResult<bool>> HasAccessAsync(string accountName, IReadOnlyCollection<string> programs, CancellationToken cancellationToken = default)

Parameters

accountName string

programs IReadOnlyCollection<string>

The programs currently active.

cancellationToken CancellationToken

Cancellation token.

Returns

Remarks

Expiry does not end access; revocation does. A code's expiry is a deadline for redeeming it, so an account that redeemed in time stays admitted after the date passes. Ending a tester's access is done by revoking the code.

Program names are normalised; a null or empty list, or one with no valid names, is false without querying — a gate configured with no programs admits nobody by code.

RedeemAsync(string, string, CancellationToken)

Redeems a code for an account: takes one use and records the permanent link, atomically.

Task<DatabaseResult<AccountBetaCodeData>> RedeemAsync(string accountName, string code, CancellationToken cancellationToken = default)

Parameters

The redeeming account; stored lowercase.

code string

The code as the player typed it.

cancellationToken CancellationToken

Cancellation token.

Returns

Task<DatabaseResult<AccountBetaCodeData>>

Remarks

An unknown, revoked, expired or used-up code all fail with the same NOT_FOUND and the same message, "That beta code is not valid.", and a malformed code fails with that message too. Registration calls this anonymously, so any difference between those answers would let a script tell a real code from a guess. The caller must pass the message through unaltered and must not add its own distinctions.

Redeeming a code the account already holds fails VALIDATION_ERROR and consumes nothing. The use is taken by one conditional UPDATE (use_count < max_uses, not revoked, not expired), and that WHERE clause is the concurrency control: two accounts racing for a code's last use cannot both succeed.
