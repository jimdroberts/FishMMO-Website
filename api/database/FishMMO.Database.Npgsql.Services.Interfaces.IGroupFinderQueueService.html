Service interface for the dungeon group finder's queue: who is waiting for a group, and the one operation that turns waiters into a party with an instance.

public interface IGroupFinderQueueService

Remarks

The queue is shared by every scene server on a world server, and every one of them runs the same matching pump against it. Nothing here assumes a single matcher: the methods that change a row's state are single statements or single transactions whose WHERE clauses re-assert the state they expect, so two servers acting on the same rows at once produce one winner and one no-op rather than a character in two groups.

All methods return DatabaseResult or DatabaseResult<T>. Write operations go through the BaseService execution wrappers for transient-failure retry and exception mapping.

Remarks

Forms an arena match from the longest-waiting eligible players, keeping pre-made groups together, opening the instance and writing the match and its seats, all in one transaction.

Task<DatabaseResult<ArenaMatchFormedData>> TryFormArenaMatchAsync(long worldServerId, string sceneName, int format, int templateId, int teamCount, int teamSize, DateTime pulsedSinceUtc, int maxCandidates = 128, ArenaRatingSource ratingSource = default, ArenaComposeOptions composeOptions = default, CancellationToken cancellationToken = default)

Task<DatabaseResult<ArenaMatchFormedData>>

The match, or a result whose Formed is false when no full match could be composed.

Remarks

The arena counterpart of TryFormGroupAsync(long, string, int, int, DateTime, SceneType, byte, byte, CancellationToken), with the same guarantees: the candidates are row-locked with plain FOR UPDATE, eligibility is re-asserted inside the transaction, and either everything is written or nothing is. Composition — which waiter sits on which team — is decided by ArenaMatchComposer on the locked candidates, so the transaction has nothing to decide and the rule is testable on its own.

Eligibility here is the arena's: a seat in a match that has not ended, or a usable dungeon or arena instance held by the character, excludes them. Party membership does not, because arenas are the place a party queues together.

The instance row is written private with no owning party; the match row is what says who is in it. It is still inserted under the one-instance guard, against every seat.
