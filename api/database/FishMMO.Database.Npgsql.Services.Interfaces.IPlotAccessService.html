Returns

Task<DatabaseResult<int>>

Remarks

Replaces rather than adds. A grant is the whole answer to "what may this person do here", so a re-grant that merged with what was already there could never take a permission away — an owner narrowing a friend's access would watch it succeed and change nothing.
