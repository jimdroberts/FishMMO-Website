The one world clock: the single world_clock_control row every scene server adopts on its next pulse, and the admin writes that set, shift, pace, hold and resume it.

public interface IWorldClockControlService

Remarks

World time is world milliseconds since the calendar epoch, and the row stores an anchor rather than a value: world ms now = base_world_ms + rate × max(0, db_now_ms − base_reference_ms), floored, computed IN SQL against clock_timestamp(). No caller's clock enters the arithmetic, so every scene server and the panel agree to the millisecond.

Every write is ONE statement. It locks the row, computes world-now from it at the database instant, re-anchors there, bumps revision, stamps updated_by and updated_at, and returns the new reading — exact to the millisecond and free of any read-modify-write race between two admins. Each write also carries an idempotency key (taken once, outside the retry loop), so a retried write whose first attempt committed but lost its reply is not applied twice; that matters for ShiftAsync(long, string, CancellationToken).

The row is seeded by scene servers (EnsureSeededAsync(long, CancellationToken)), never by an admin write. Every write fails with NotFound and a sentence saying so when no scene server has run against this database yet.

A write is adopted by the scene servers on their next pulse. An acknowledgement says what was WRITTEN, never that it has taken effect.

Methods

EnsureSeededAsync(long, CancellationToken)

Creates the row if there is none (INSERT … ON CONFLICT (id) DO NOTHING): world time = the database's now − the epoch (floored at zero), real-time pace, revision 1. An existing row is left exactly as it is, epoch included.

HoldAsync(string, CancellationToken)
