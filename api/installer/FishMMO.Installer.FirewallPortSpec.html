A single firewall rule: one port or an inclusive port range, on TCP or UDP. Deserializes from install-config.json as either a bare integer (443, TCP) or a string ("7770-7999/udp", "8080/tcp", "7770-7999"). Protocol defaults to TCP when omitted.
