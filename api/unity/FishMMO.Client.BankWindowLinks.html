Remarks

The bank's own controls are in its UXML; a module's link is not, so removing the module removes the button with it. Each button starts hidden: every time the bank opens it calls OnBankShown with a setter, and the module shows the button (now or when it has asked the server) only when there is something behind it. A module registers once, before the first scene loads ([RuntimeInitializeOnLoadMethod]).
