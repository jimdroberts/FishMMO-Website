Cached static casters for the main light's cascaded shadows: the GPU-driven props' static casters (structures, rocks, cliffs — TerrainGpuRenderer.ShadowCache.cs) are drawn into a persistent copy of URP's cascade atlas only when a cascade changes, and that copy is merged, depth-tested, into URP's own shadow map every frame after URP has drawn the rest.

Remarks

Why a merge, not a replacement. URP keeps its cascade slices and its shadow pass to itself, and every receiver (props, vegetation, GPU terrain, grass, scatter, water, the clouds' shadow reads) samples URP's map with URP's matrices. So URP still draws the shadow map — every live caster: trees and plants (their sway stays), characters, ships, scatter, grass, terrain — and only the batch group's static casters move out of it (TerrainGpuRenderer.Brg.cs leaves them out of the main light's culling while this serves the camera). After URP's pass the cache is merged into the same map with the depth test, so each texel keeps the nearer of the live and the cached depth: exactly what drawing them together gives. Nothing a receiver reads changes.

Windows, not URP's slices (2026-11-03). URP re-fits each cascade to the camera every frame, snapped to its texels. Caching URP's slice itself meant a moving camera redrew every cascade nearly every frame (natively ~1,240 static draws a frame, +2 ms CPU, no saving). Each cascade is now cached over a window: URP's slice at the refresh with its orthographic projection widened by MarginDivisor of its texels on each side (and a quarter of its depth range at each end), at URP's own texel size and rotation. URP's slice in a later frame is the same orthographic grid moved by whole texels (stable cascades), so it maps into the window as a whole-texel shift and a depth offset (TryMap(in Window, in CascadeKey, int, int, out Mapping)), and the merge copies from there. A cascade is redrawn only when URP's slice leaves its window (its tile or its depth range), the slice's rotation, texel size, resolution or bias changes (a sun step, a setting), the atlas changes, or the static casters themselves change (a layout or an instance upload: the camera no longer counts). A redraw culls the casters itself for the whole window, from the camera's position then (TerrainGpuRenderer.RecordShadowCacheCull): its levels chosen there and drawn whole (no crossfade dither, which would freeze mid-fade), so a cached shadow can hold an instance's level from up to a margin away until its window moves on. While caching, the sky lights' directions step on a fixed azimuth/elevation lattice (SunStepDegrees): the sun's direction is a pure function of the shared clock and the lattice is a pure function of the direction, so every client steps at the same world time; between steps the windows hold.

Limits. A sun step redraws every cascade that frame. A redraw costs what every frame cost before (one indirect draw per static command; Unity pays a SetPass for each, whatever their order). Only the props' batch-group casters are cached; MeshRenderers, scatter and the GPU terrain stay live. Needs the instance index to carry the run's start (Vulkan; WebGPU with indirect-first-instance); elsewhere it does nothing.

MergeDepthTest(bool)

The merge's depth test: keep the nearer depth to the light, written as on a forward depth buffer (LessEqual), since Unity itself reverses a material's ZTest where the depth buffer is reversed (the casters' own "ZTest LEqual" reaches the GPU as greater-equal there). Passing GreaterEqual under a reversed buffer came out as less-equal, which kept the farther depth: no cached caster ever won, and an empty cache tile erased the live casters. The diagnostic overwrite copies the cache whatever it holds.
