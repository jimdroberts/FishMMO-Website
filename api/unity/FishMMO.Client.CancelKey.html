Remarks

~ exists because of the browser. A web build cannot have Escape: it always releases the pointer lock and leaves fullscreen, no page can cancel that, and the browser often does not deliver the key at all. Escape is kept beside it for the desktop client and for the times a browser does pass it through.

While the player is typing, only Escape counts. ~ and ` are characters, and a field that ate them could not hold a password containing one, or a chat line. Typing also means the cursor is already free, which is when a browser lets Escape through.

The same pair is bound in the input asset to Player/Cancel and Player/CloseLastUI, whose handlers apply the same rule through InputControlHasFocus(UITKControl); see PlayerInputController.

Remarks

A TextField delegates focus to its inner text element, so a key event targets that child; walking up catches both. Matched by USS class rather than type so every field type (TextField, IntegerField, ...) is covered, and Buttons and Labels — which are TextElements too — are not.
