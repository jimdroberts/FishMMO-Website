Remarks

The same character can be reached three ways (in the world, in the guild roster, in the party roster), and an action such as befriending someone belongs in all three. The menus keep their own entries (Inspect, Message, the rank entries) and call AppendTo(List<(string label, Action callback)>, CharacterMenuTarget) where module entries go, so a removed module leaves no entry naming it. A module registers once, before the first scene loads ([RuntimeInitializeOnLoadMethod]), as with GameMenuEntries.
