Remarks

Separate from ClientDisplaySettings because it writes to a scene object rather than to Unity's global state, and that object does not exist for the whole session. The camera lives in ClientPreboot and is picked up by KCCPlayer when it takes ownership, so a value applied at boot has to survive until then — it does, because RotationSpeed is a plain field on a component that outlives the scene loads between boot and play.

Sensitivity only has an observable effect while the cursor is locked, which is the state the mouse drives the camera in. With mouse mode on the cursor is free and the camera does not turn at all, so the slider looks broken if tested there — it is not, there is simply no look input to scale.

Remarks

SMAA rather than Off. The camera ships with antialiasing disabled, which is what made character silhouettes visibly stair-stepped; a default that looks broken is a poor one. Chosen over FXAA because it keeps texture detail instead of softening the whole frame, and over TAA because TAA ghosts on a camera that orbits the player.

MouseDegreesPerCount

Degrees the view turns for one count of mouse movement: sensitivity × 0.022.

public static float MouseDegreesPerCount { get; }

Property Value

float

Remarks

The common mouse-look scale, so the same number turns the view by the same amount for the same movement of the mouse. Nothing is scaled by frame time, and the counts come in raw (the browser is asked for unaccelerated movement, see PointerLockGuard.jslib).

Not scaled by the field of view. It was, by tan(fov/2) against a 73.74-degree reference, to keep the picture moving the same at any view: at the camera's 60 degrees that turned 23% less per count than the same number elsewhere, and a player's usual sensitivity felt slow (2026-11-11), so the scale is the plain one.

ApplyLookSensitivity(float)

Sets the look sensitivity, and puts the camera into degrees.

public static bool ApplyLookSensitivity(float value)

Parameters

value float

The sensitivity. Clamped to the supported range.

Returns

bool

true if a camera was found and set to take degrees; false if there is none yet.

Remarks

Clamped rather than trusted. The value is a float in a text file the player can edit, and it scales raw mouse movement: a large one makes the view unusable at exactly the moment the player would need to reach the menu to put it back, and zero makes the camera immovable.

The look input now arrives at the camera already in degrees (PlayerInputController converts counts with MouseDegreesPerCount), so the camera's own RotationSpeed multiplier is held at 1 rather than carrying the sensitivity.

LoadSaved()

The saved sensitivity, carrying over one stored under the old meaning.

float

Remarks

The setting used to be the degrees turned per count outright (0.1 to 1, default 0.5), stored under LegacyLookSensitivityKey. It is converted once into the sensitivity that turns the same amount per count, so nobody's view changes speed under them except where the old value lies past the new maximum; the old key is then removed.
