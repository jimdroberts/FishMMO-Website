Remarks

Two parts, both following Mode:

  1. Safe colours, the part that matters. Mode moves the colours that carry meaning (hostile, friendly, neutral; a better or worse stat) to ones that stay distinct, and UITKThemeManager puts a fish-cvd--* class on every panel root, under which FishMMO-Theme.uss redefines the meaningful tokens (resource bars, danger, rarity, map markers).
  2. The correction filter (ColorVisionFeature): a full-screen daltonisation of the 3D view after post-processing, so the world itself separates better. It runs under the UI, which already has its safe colours, and costs one full-screen pass while on.

The values are held in statics, set at boot (ApplyAll()) and on every change, so the filter reads fields each frame and never the settings store.
