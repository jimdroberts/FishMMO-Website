Remarks

Off by default. The overlay is a diagnostic: a player who has never asked how much the game sends has no use for a table of byte counts in the corner of the screen, and a fresh install should look the way it did before the overlay existed.

Why the settings live here rather than on the panel. For the reason ClientCrosshairSettings gives: UITKNetworkStats is a panel whose OnStarting can re-run, and the options panel must be able to read and write the choice in a scene where the overlay has not started yet. These are plain reads off ClientSettings, so neither side has to wait for the other.

Visibility is the only thing the setting owns. Sampling follows it: the overlay reads the transport's counters only while it is shown, so turning it off also stops the once-a-second connection statistics read the transport makes on its behalf (see TransportTraffic.Capture).
