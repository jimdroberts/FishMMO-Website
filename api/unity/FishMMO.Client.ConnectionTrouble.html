Remarks

The game connects only over QUIC (WebTransport), with no fallback. Players whose security software or network blocks it otherwise see a generic "could not sign in". The transport records how the attempt went (FishNet.Transporting.WebTransport.ClientConnectDiagnosis), and this turns that into an explanation.

An open time under LocalOpenMilliseconds cannot be a real server: a QUIC handshake plus the WebTransport request is at least one round trip. The confirmed case (ESET, 2026-11-12) answered in about 1 ms. A player on the same machine or network as the server can also open that fast; they see this only if that server then says nothing.
