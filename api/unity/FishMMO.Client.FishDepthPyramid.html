Remarks

Unity's own occlusion culling works only for static scene renderers; the props are data drawn indirectly (CliffRockInstancing), so nothing culled them behind a hill. The pyramid is last frame's: a prop's sphere is grown by how far the camera has moved since, and anything off last frame's screen is drawn, so a step reveals what it should. One atlas holds every level (level 0 at half the screen, the rest beside it), so one read-write texture builds and serves it.
