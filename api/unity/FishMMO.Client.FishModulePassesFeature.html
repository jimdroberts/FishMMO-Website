Class FishModulePassesFeature

Namespace
FishMMO.Client
Assembly
FishMMO.Client.dll

Hosts the modules' render features (ModuleRenderFeatures) on a URP renderer (Phase 4 of the core and modules plan, 2026-11-18): the World Simulation module's clouds, height fog, froxel fog and heat shimmer stood on the renderers themselves, so a project without the module had renderers with missing features. This core feature stands where they stood and draws whatever modules are installed, in their registered order; with none, it draws nothing.

[DisallowMultipleRendererFeature("Fish Module Passes")]
