The world's shared render passes, on every renderer: the depth pyramid (occlusion culling for instanced props), the shadow cascade bounds (casters skip cascades that do not need them), the WebGPU light table (every lit pass reads its additional lights and probes from it) and the cached main-light shadows.

Remarks

These were queued by FishCloudsFeature, the one feature every renderer happened to carry, so the clouds owned the world's lighting: a game without the weather module would have lost its light table and shadow cache with them. They are core now (Phase 4 of the core and modules plan, 2026-11-17), and the clouds draw clouds.
