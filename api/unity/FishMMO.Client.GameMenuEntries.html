Remarks

The menu's own buttons (Resume, Options, Channels, Dungeon, the quits) are in its UXML; a module's button is not, so removing the module removes the button with it and leaves nothing in the menu that names it. A module registers once, before the first scene loads ([RuntimeInitializeOnLoadMethod]); the menu lays the entries out in Order where its menu-module-entries element stands.
