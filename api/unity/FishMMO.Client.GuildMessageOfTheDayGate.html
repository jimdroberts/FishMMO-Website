Remarks

The server sends the guild's text to a member every time they connect to a scene server, which is every zone change as well as the login, and again to the whole guild whenever an officer edits it. Printing every copy would repeat the same line at each zone line. So the rule is: once per login, and again only when the text is different from what was last shown — an edit, a new guild, or a different character.

An empty message is remembered but never printed, so a guild that sets one later while the player is online still has it announced.
