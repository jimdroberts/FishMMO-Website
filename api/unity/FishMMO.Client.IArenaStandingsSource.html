The season standings the arena board shows in its Leaderboard view, supplied by the Leaderboards module.

public interface IArenaStandingsSource

Remarks

The arena board does not know how standings are read: with no source (the Leaderboards module is not installed) its Leaderboard tab is hidden. A source asks the server when the board opens the view, keeps one request outstanding (Tick(Client, float)) and raises Changed when what it would show changes.
