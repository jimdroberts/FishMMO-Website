A renderer whose static shadow casters the cached main-light shadows (CachedMainLightShadows) draw into their cache: the GPU-driven terrain and props.

public interface IShadowCacheCaster

Remarks

The cache is core rendering; what it caches belongs to whichever world module draws it. A caster joins ShadowCacheCasters while it is live, so the cache iterates casters, never a module's renderer type (Phase 4 of the core and modules plan, 2026-11-17).
