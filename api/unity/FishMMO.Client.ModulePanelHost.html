Remarks

A module's panel lives in the module's folder as a prefab, not in the GUI scene, so removing the module leaves the scene without a missing script, and nothing outside the module names the panel.

Each panel keeps its prefab's name, which is its UIManager key: it is instantiated under an inactive holder, renamed, then moved into the scene, so its Awake (where it registers) sees the right name. A panel instantiated after the client is set still receives it: registration injects it.

A scene with no such label costs one location lookup.
