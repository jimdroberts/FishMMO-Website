Remarks

The colour comes from the stylesheet. The line is stroked in this element's own resolved color, which UINetworkStats.uss sets from a theme token per direction, so no colour is written in code and the legend beside the headline and the line cannot drift apart.

Both lines share one scale, set by the panel: two lines drawn to their own peaks would make a trickle of uploads look as large as the downloads.

An unknown second is a gap. The pen lifts over a NaN point and puts down again at the next known one (see GraphY(double, double, float)), so a second the transport could not measure never reads as a second with no traffic.
