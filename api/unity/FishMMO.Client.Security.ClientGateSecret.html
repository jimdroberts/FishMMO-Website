IL-embedded client gate secret.

The default here is a sentinel, and this file is tracked so the project always compiles. The real value lives in the gitignored ClientApiSecret.generated.cs, written by FishMMO Dashboard > Game Settings (or by CI substituting FISHMMO_CLIENT_GATE_SECRET into GeneratedFileTemplates/ClientApiSecret.generated.cs.template), which implements FishMMO.Client.Security.ClientGateSecret.Configure(FishMMO.Client.Security.ClientGateSecret.Values) to overwrite it. See HostConfig for why the generated file no longer declares the whole class.
