Remarks

Made off the main thread. A recipe is pure arithmetic (SoundSynth), so it runs on the thread pool and only the clip is made back on the main thread, when Get(string, Func<float[]>, int) is next asked. Until then Get(string, Func<float[]>, int) returns null and the caller stays silent for those few frames: a rain loop that starts a quarter of a second late is better than a frame that hitches to make it. A recipe must not call Unity — on a worker that throws, and the sound would never be heard.

WebGL has no threads: there the recipe runs where it is asked for.
