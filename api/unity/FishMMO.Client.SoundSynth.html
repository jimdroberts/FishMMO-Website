The building blocks every synthesised sound is made from: seeded noise, filters, envelopes and the seamless loop. There are no audio files in the project; each sound is a recipe over these, run from a fixed seed.

Remarks

The same seed makes the same sound on every machine. Everything here is plain managed arithmetic in single precision, run in one order, with no Unity call inside: the same recipe gives the same samples on every client, and it can run off the main thread (SoundLibrary). Only ToClip(string, float[], int) touches Unity.

Filters are the RBJ cookbook biquads (Bristow-Johnson's Audio EQ Cookbook), direct form I in float.

NormalizeLoudest(float[], int, float, float)

Scales a sound by its loudest stretch rather than its loudest sample: the loudest windowSeconds is brought to rms. A sound whose energy is a long roll behind one sharp crack (thunder) would otherwise be set by the crack, a millisecond long, and the roll left at a hundredth of full level. Follow with Limit(float[], int, float, float): the crack is now above full scale.
