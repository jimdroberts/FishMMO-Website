Remarks

No component on the object. The outline is not something an object carries; it is a property of the player's aim. This holds one target and the list of its renderers, gathered when the target changes, and TargetOutlineFeature (a URP renderer feature on every renderer) draws them. Nothing is added to, or allocated per, interactable object, and with no target the feature adds no pass at all.

Who drives it. UITKTarget's hover handling: it already resolves what the pointer rests on through InteractableResolver, the same rule the interact key uses, so the highlighted object is always the one the key would act on.

What it draws. The UnityEngine.MeshRenderers and UnityEngine.SkinnedMeshRenderers under the target, as gathered by Show(Transform); something that swaps its meshes while outlined calls Refresh(). Objects drawn by the GPU-driven systems (terrain, scatter, batched procedural props) have no renderer and cannot be outlined this way. Only the visible parts are outlined: the ring follows what can be seen, not what is behind a wall.
