Class UITKAbilities

Namespace
FishMMO.Client
Assembly
FishMMO.Client.dll

UI Toolkit abilities panel. Replaces the legacy UGUI UIAbilities / UIAbilityButton: renders the character's abilities, known abilities, and known ability events as tabbed icon slots. Hovering shows the entry tooltip; left-clicking a known ability picks it up onto the shared drag object so it can be assigned to a hotkey.
