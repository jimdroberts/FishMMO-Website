Remarks

Two tabs, because there are two kinds of thing. An ability on the Abilities tab is finished — it can be dragged onto a hotkey and used. Everything on the Knowledge tab is a part: a base ability is the core of a craft, an effect is something a base ability is configured with, and neither does anything until they are combined at an Ability Crafter. The panel used to show all three as identical icon squares, so a template read as an ability that simply refused to work (issue #247).

Rows, not bare icons. Each entry carries its name and the numbers that distinguish it, and selecting one renders its full description in the pane beside the list — the same TooltipContent the cursor tooltip draws, through the same UITKTooltipView. An icon grid could not show any of that, so two abilities that differed only in cooldown and range looked the same until the player hovered each in turn.

Only the Abilities tab drags. A click that cannot pick an entry up writes the reason to the status line under the list, where the tab's standing hint otherwise sits.
