Class UITKControl

Namespace
FishMMO.Client
Assembly
FishMMO.Client.dll

Abstract base class for UI Toolkit-backed controls. Mirrors the lifecycle of UIControl but drives a UnityEngine.UIElements.UIDocument instead of a UGUI Canvas. Automatically registers and unregisters with UIManager on Awake/OnDestroy.

public abstract class UITKControl : MonoBehaviour
