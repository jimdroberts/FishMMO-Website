Class UITKGuild

Namespace
FishMMO.Client
Assembly
FishMMO.Client.dll

UI Toolkit guild panel. Replaces the legacy UGUI UIGuild / UIGuildMember: renders guild members as dynamic rows with name/rank context dropdowns, and handles create/leave/invite actions. All guild broadcasts are preserved verbatim and the shared UGUI dialog/dropdown overlays are reused via the UIManager.
