Remarks

The bottom-centre block is a stack of separate UIDocuments — hotkey bar, resource bars, buff and debuff strips, cast bar, with the chat log's lower edge beside them — and separate documents cannot be laid out relative to each other, so every relationship between them is a fixed offset written in each panel's stylesheet against the first bar's measured top edge (see UIResourceBar.uss). Those offsets are right for one row. Each further row a stacked hotbar draws is one HotbarRowPitch taller, so every panel in the block adds that much to its own offset, and the chat log gives the same ground from its height so that its top edge — which the toast stack and the party frame are measured against — stays where it always was.

A margin, not the offset itself. The inset is applied as an inline margin-bottom on the element the stylesheet anchors with bottom. For an absolutely positioned element Yoga adds the margin to the offset, so the stylesheet's own number keeps its meaning and nothing here has to know it. And a panel the player has dragged is anchored by an inline top with bottom: auto, for which a bottom margin moves nothing — a placed panel stays exactly where it was put, with no test for it here.

Derived from settings rather than published by the hotkey bar, so no panel depends on which document happened to start first: each reads the inset when it starts and again on OnChanged.

Remarks

Needed because the log gives ground from its height rather than moving: a panel that moved up by the inset would carry its top edge into the toast stack above it.

ChatMinimumHeight

The shortest the chat log is allowed to become: its tab strip, its input and two lines.

public const float ChatMinimumHeight = 80

Field Value

float

Remarks

A floor rather than a promise. A game that stacks five or more bars has asked for more of the screen's lower third than the log can give up; the log then keeps this much and sits behind the top rows, which is a layout that game has to design for itself.

HotbarRowPitch

Vertical distance from one stacked hotbar row to the next, in panel units.

public const float HotbarRowPitch = 51

Field Value

float

Remarks

A 48-unit slot plus the 3-unit gap between rows: .hotkey-slot and .hotkey-row in UIHotkeyBar.uss. Change either there and this with it.
