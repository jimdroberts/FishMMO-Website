Remarks

The single output path for every description in the game. A tooltip used to be one Label holding a rich-text blob, which meant a stat could not be aligned, a change could not be shown beside the value it changed, and nothing could be reused anywhere but under the cursor.

Rows become elements here, so the same content renders as a hover tooltip, as the details pane in the abilities panel, and as the crafting preview — the three places that need it — with the layout coming from USS rather than from tags baked into a string. Rich text is still honoured inside a row's text: UI Toolkit's Label supports <b>, <i>, <u>, <color>, <size> and <mark>, so content that genuinely needs inline formatting can carry it.
