Class TimedCache<TKey, TValue>

Namespace

A thread-safe, write-through TTL cache where entries expire after a fixed duration from when they were stored. Reads do NOT extend the lifetime (unlike LastSeenCacheTracker<TKey, TValue>).

Supports bounded head-first SweepExpired(TimeSpan, int, int) for memory management.

Ages are measured on MonotonicClock, not the host's wall clock. A TTL is a duration, and on DateTime.UtcNow a clock stepped back an hour kept every entry "fresh" for that hour: the world server's available-scene cache served the same instance list, populations and all, long after the instances had filled or gone.

Remarks

Reads the clock itself rather than taking a "now": the entries were stamped by Set(TKey, TValue) on MonotonicClock, and a caller-supplied instant from any other clock would compare two unrelated numbers.
