Remarks

The server isolates each unit of repeating work (a behaviour's update, a periodic callback, an NPC brain, a weather scene) in its own try/catch so one failure cannot stop the rest. Isolation alone turns a deterministic throw into a full stack trace on every pass: 60 a second from a behaviour, 1,500 a second from fifty NPCs sharing a broken archetype. That drowns the first trace, which is the only one anyone needs.

One instance per unit of work. The first failure, and any failure whose exception type or message differs from the last, is logged in full. Identical repeats are counted and summarised at most once per SummaryIntervalSeconds. A success after failures logs one recovery line with the count, so a transient fault reads as transient.

Not thread-safe: each instance belongs to the thread that runs its unit of work, which for every current caller is the main thread.
