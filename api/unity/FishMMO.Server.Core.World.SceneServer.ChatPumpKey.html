Remarks

The same key the pump's SQL filters on (ChatService.FetchPumpAsync): the world column for World, Trade and Discord, the message's first word for Party and Guild, and for a Tell the target's address — the quoted name when the row starts with a quote, otherwise the first word (FishMMO.Shared.ChatTellAddress).
