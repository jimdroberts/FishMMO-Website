Engine-agnostic public API of the player-to-player trade system.

public interface ITradeSystem : IServerBehaviour, IServerComponent

Remarks

Other systems only ever need to ask one thing of it: whether a character is mid-trade, so a teleport, a scene hand-off or an instance return can close the session before it moves the character. Everything else — invitations, offers, acceptance, the atomic exchange — is driven by client broadcasts and the system's own range tick.
