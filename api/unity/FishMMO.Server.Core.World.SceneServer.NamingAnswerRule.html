Remarks

Found, either formanswered with the name.
Not found, batchedanswered with an empty name: the client drops what was waiting on it rather than hold it for the session.
Not found, singlenot answered. The single-ID reply never had a not-found form, and the client that asked in it asks again.

A lookup that could not run (the database did not answer) answers nobody, in either form; that is decided before this rule is asked.
