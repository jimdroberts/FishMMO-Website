int

The number of IDs added.

Remarks

limit is what the request was admitted for: the message's own cap, and then the connection's budget, are both charged per entry before anything is read, so an entry past the limit is not looked at at all. A repeated ID is charged and not looked up twice; an honest client never repeats one.
