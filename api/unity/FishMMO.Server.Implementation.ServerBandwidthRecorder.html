Remarks

One per process, owned by the tier's system. LoginServerSystem, WorldServerSystem and SceneServerSystem each start one when they finish initialising and stop it when they deinitialise. It is a plain helper rather than a ServerBehaviour so that no server scene needs another asset in its behaviour list, and so the three tiers cannot drift apart.

The source is the transport's own counters (FishNet.Transporting.WebTransport.TransportTraffic.Capture(out FishNet.Transporting.WebTransport.TransportTrafficSnapshot)): FishNet bytes counted by the WebTransport socket, and msquic's process-wide UDP payload and datagram counts, which include the handshakes and refused connections that never became a session — exactly what an operator pays egress for. FishNet's StatisticsManager is disabled on servers and is not used.

Nothing runs on the main thread but the timer. Every 60 seconds the periodic system hands one unit of work to the async worker; that work reads the database clock, captures the counters (allocation-free, any thread), files the interval in the ServerBandwidthLedger and writes every pending minute in one SET-upsert. A unit is single-flight: while one is still running the next tick is skipped, and because the counters are cumulative the following sample simply covers the longer interval.

A failure never double-counts, never blocks, and is never silent. A failed clock read defers the sample (nothing is lost). A failed write keeps its minutes pending and they are re-sent with the next sample — safe, because the write is a SET of each minute's running total, keyed before the retried delegate runs. Only after MaxPendingMinutes minutes of failures are the oldest dropped, and the drop is logged with its count. Faults go through one RepeatingFaultLog, so a database that is down for an hour logs its first error in full, a summary every fifteen minutes and one recovery line.

Remarks

Called after the transport has stopped, so the sample includes the disconnects; the native counters survive the library's deinitialisation (they are carried), so the capture is still measured. Skipped, with a line in the log, when a write is still running past the timeout or the shutdown budget is too low to spare — the budget belongs to the character saves first.
