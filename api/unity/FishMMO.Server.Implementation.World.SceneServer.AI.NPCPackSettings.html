Remarks

Off by default, so every spawner authored before packs existed runs unchanged. A table or scene serialized without this block deserializes it with Enabled false, and a spawner whose pack is off never creates a group.

Inline rather than a separate asset. A pack's tuning is four numbers that belong to one placement; an asset would be a second thing to author, register with the server's addressables and keep out of client groups, for no reuse anyone has asked for. The members and their roles are the spawner's own entries (NPCSpawnableSettings.PackRole).
