Remarks

Achievements were once fetched on login and never written back, so progress reset to the loaded values every session. The save leg is shaped like the ability one: MarkChanged() advances the version on mutation, Capture(ICharacter, CharacterRows) advances it again, and the confirmed write clears the mark only when the version still matches.
