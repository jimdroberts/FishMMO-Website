Remarks

Visibility is the gate's own rule. A command is listed only when TryParseCommand(string, IPlayerCharacter, ChatBroadcast) would run it for this caller: above Banned and at or above the command's registered level. The level is the caller's server-loaded AccessLevel; nothing the client sends reaches this. A player therefore never sees /gm or /admin, and a game master never sees /admin.

Sub-commands are not listed here. /gm and /admin are one entry each whose summary points at their own help, which is derived from their tables and is itself behind their access gate. Nothing in this listing could leak a sub-command name.

No oracle. /help <command> answers a command the caller may not use with exactly the line it answers a command that does not exist, and echoes nothing typed.

Pure: nothing here touches server state, so the rules can be tested against any registry.
