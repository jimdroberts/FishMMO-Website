Remarks

Once per scene, not per instance. The Unity NavMesh is global, not per physics scene, and a scene server can run several stacked instances of one world scene at the same coordinates. Their NavMeshes would be identical and overlap exactly, so the first instance adds it and the last one to unload removes it.

And its climbables' links. Each of the scene's ladders, rope ladders and ropes (Climbables) becomes a two-way link from its foot on the lower floor to its landing on the upper one (LinkEnds(in SceneClimbable, out Vector3, out Vector3)), in the "Climb" area so only archetypes that climb path over them (ClimbArea). Links are global like the NavMesh, so they too are added once per scene and go with it. Made at load from the same list the players' climbing reads, so the two never disagree and no bake is needed for them.

A plain class rather than part of NavMeshSystem, so tests can drive it without FishNet.
