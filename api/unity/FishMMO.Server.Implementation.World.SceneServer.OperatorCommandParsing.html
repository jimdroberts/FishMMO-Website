True when a positive duration no longer than MaximumDuration was parsed.

Remarks

A bare number is minutes, because minutes are what a moderator reaches for first and "mute 10" meaning ten seconds would be a mute that has lapsed before the player reads it. Zero and negative values are refused rather than meaning "none": a mute of nothing is a typo, and treating it as permanent would be a far worse one.

TrySplitLeadingCharacter(string, out string, out string)

Decides whether a command's leading word names a character or is already its first real argument.

public static bool TrySplitLeadingCharacter(string arguments, out string name, out string rest)

Parameters

arguments string

The command's argument text.

name string

The named character, or null when the caller is the target.

rest string

The arguments after the name, or all of them when there is no name.

Returns

bool

True when a character was named.

Remarks

For the administrator commands whose target is optional — /admin setgold [character] <amount>, /admin heal [character]. The rule is deliberately about the word's shape and not about whether a character by that name exists: nothing, or a number, means the caller; anything else is a character name, and if that character is not on this scene server the command says so rather than quietly acting on the caller.

The alternative — "a name if one is online, else yourself" — turns a mistyped name into a grant to the administrator's own character, which is exactly the silent wrong-target failure an economy command must not have.
