What one attempt to spawn an object came to.

public enum SpawnOutcome

Fields

AtCapacity = 2

The spawner is already at its maximum.

Failed = 6

The pool produced nothing, or an exception interrupted the spawn and it was rolled back.

Misconfigured = 4

The chosen entry cannot be spawned as authored — empty, no network object, a prefab the network manager does not know — or there is no network manager.

NothingEligible = 3

Unique spawnables are on and every entry is already alive.

SceneNotLoaded = 5

The scene instance is not loaded.

Spawned = 0

An object was spawned and is tracked.

SpawnedUntracked = 1

An object was spawned, but its prefab has no ISpawnable, so the spawner can neither count it nor hear of its despawn.

Remarks

Named rather than a bool because the callers need to tell "the slot is spent" from "the object is still owed": see ConsumesTimer(SpawnOutcome).
