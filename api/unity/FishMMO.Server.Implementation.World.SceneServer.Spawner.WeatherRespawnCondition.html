Remarks

The creature that only comes out in the rain, and the one that will not. Both are this one condition with Invert either way, dropped onto a spawner beside any other condition it already has — nothing about the spawner knows or cares that it is weather doing the gating.

It gates the respawn, not the life. Something that spawned in a storm stays when the storm passes; it simply is not replaced while the sky is clear. Despawning a creature the moment the weather turned would take a mob out from under whoever was fighting it.

Server-side, and not predicted. A spawn is authoritative and always was — the client is told what appeared. So unlike everything else in this weather pass, this reads the server's own WeatherQuery sample at whatever tick it is called on, and there is nothing for a client to agree with.
