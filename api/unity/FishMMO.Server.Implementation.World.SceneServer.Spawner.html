WildlifeCatalogue

Every wildlife species the server places, and the limits on how many: read by WildlifePlanner when a scene is cut (WildlifeSpawnerCut writes its plan into the scene as ObjectSpawners). Built by the wildlife builder (FishMMO Dashboard → Maintenance → Wildlife).

WildlifePlanner

Plans a world scene's wildlife spawners when it is cut: big overlapping areas over the open country, each with the species its biomes support, plus a group at each den point of interest and some cave mouths. The cut writes the plan into the scene as ObjectSpawners (WildlifeSpawnerCut), which the spawn-table bake carries to the server like any other. At spawn time the runtime keeps each species on its own ground and its herd together (SpawnerRuntime).
