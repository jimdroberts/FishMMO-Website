The one place a character's discovered-waypoint pages are turned into rows and merged. Used by the unlock path (write on change) and by the character system's periodic and despawn saves (retry of anything still dirty).

Remarks

The database merge is an OR, so both callers may write the same page without either losing bits, and neither needs to know about the other. What each caller does with the result — confirming the pages on the main thread — is the same too, hence MarkPersisted(List<CharacterWaypointData>, Func<long, ICharacter>).
