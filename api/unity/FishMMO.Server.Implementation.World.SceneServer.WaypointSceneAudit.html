Remarks

The map draws from the baked Waypoints; the server resolves a travel request from the live WaypointRegistry. They are keyed the same way, (scene, index), and nothing else ties them together. A waypoint added to a scene without a cache rebuild is discoverable on foot and then invisible on every map; a waypoint in the cache whose object no longer spawns is drawn and refused. Both are silent authoring drift, and the only place that holds both sides at once is a scene server that has just finished loading the scene.

The comparison is a pure function over the two index sets so it can be pinned by a test; the scene-server hook only gathers the inputs and logs the answer.
