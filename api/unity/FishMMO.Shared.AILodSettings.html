Configuration asset for AI LOD (Level-of-Detail) distance thresholds and update rates. Assign to LodSettings to override the default values.

The system uses the NPC's FishNet NetworkObject.Observers to determine how many players can see the NPC. If no observers exist, the NPC is Dormant. When at least one observer exists, a fast squared-distance check against the nearest observer determines the tier.

Tick scheduling: Each tier has a frame stagger modulus that spreads NPC updates evenly across frames. At 60 FPS the approximate update intervals are:

TierModulus → Approx. Interval
Active3 → ~50 ms (full AI pipeline)
Nearby12 → ~200 ms (simplified — no BT, no boss, no sweep)
Far60 → ~1 s (minimal — no combat, wander/idle only)
Dormant120 → ~2 s (wake-up check only)

Behavior simplification: Lower tiers run progressively simpler AI:

TierSystems Running
ActiveBehaviorTree, StateMachine, Abilities, Threat, GroupAI, BossScripts, EnemySweep
NearbyStateMachine, Abilities, Threat, GroupAI (no BT, no BossScript, no EnemySweep — relies on event-driven combat entry)
FarStateMachine only (wander/idle/return home — no combat, no threat, no sweep)
DormantDisabled — only periodic LOD re-evaluation to wake up when a player approaches
