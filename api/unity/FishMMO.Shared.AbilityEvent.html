Abstract base class for ability events. Extends Trigger to provide ECA-driven conditions and actions. Ability requirements (resources, faction, archetype, attributes) are defined as ECA conditions on the inherited Conditions list or on the parent ActivationConditions list.

Remarks

Written as the CHANGE it represents rather than as absolute numbers, because that is what the player is deciding about: an effect on its own has no cast time, it adds one. Signs are therefore always shown, and the tone says whether the change helps.

IsCompatibleWith(AbilityTemplate)

Whether this effect does anything on an ability built from template.

public virtual bool IsCompatibleWith(AbilityTemplate template)

Parameters

template AbilityTemplate

The base ability the effect would be added to.

Returns

bool

True when the effect can be part of that ability.

Remarks

The one statement of which effects go on which abilities. Crafting, premade offers, the craft window and AddEvent(AbilityEvent) all ask it, so an effect the server refuses is one the window never offers and a stale database row can never smuggle in.

The default refuses summon spells. A PetAbilityTemplate spawns no ability object, so the tick, hit, spawn and destroy phases these effects run in never happen on one. Crafting one onto a summon used to be accepted all the same, and all it did was fold the effect's cast time, cooldown and cost into the spell: a player paid for a fireball and got a slower summon, or found a negative cast-time effect made a faster one. AbilityOnSummonEvent is the effect that belongs on a summon, and inverts this.
