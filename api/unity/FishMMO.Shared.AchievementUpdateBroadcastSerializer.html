Remarks

Hand written for one field. TemplateID is a deterministic 32-bit hash (CachedScriptableObject.AddToCache), so it spans the whole signed range and FishNet's signed-packed form spends FIVE bytes where unpacked spends exactly four. The login sync ships every achievement the character has progress on in one AchievementUpdateMultipleBroadcast, and progress messages then arrive throughout play. Value stays packed — it is an unsigned progress count and small, and unsigned packing has no zigzag to defeat it — and Tier is already a single byte.
