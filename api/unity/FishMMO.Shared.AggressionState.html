Manages the aggression (threat) system for a single NPC. Owns the AggressionController instance, subscribes to global damage/heal/kill events, and tracks the per-NPC target re-evaluation timer.

Extracted from AIController to keep the controller focused on navigation and state management. One instance per NPC — plain C# class.

Event-driven combat entry: When the threat table transitions from empty to non-empty (first damage received), the OnCombatInitiated callback is invoked for immediate combat entry without waiting for the next physics sweep.

Replay safety: Event handlers are guarded to ignore damage/heal/kill events fired during prediction replay. Global combat events are not replay-suppressed by the damage controller, so we suppress them here.

Configure(float, float, float, float, float, float)

Sets the threat table's weights. Existing entries keep their points; only how future events are scored and how fast entries decay changes.

public void Configure(float damageWeight, float healingWeight, float hitBonus, float decayRate, float staleTimeout, float varietyChance)

Parameters

damageWeight float

Threat per 1 point of damage taken.

healingWeight float

Threat per 1 point of healing witnessed on a combat participant.

hitBonus float

Flat threat added per hit, regardless of damage.

decayRate float

Threat lost per second while no new events arrive.

staleTimeout float

Seconds before a drained threat entry is forgotten.

varietyChance float

Chance target selection picks the second-highest threat.

Remarks

Separate from the constructor so a controller whose archetype changes after it has been initialised — a spawner override on a recycled instance — can retune the table it already has instead of rebuilding it and losing its dispatcher registration.
