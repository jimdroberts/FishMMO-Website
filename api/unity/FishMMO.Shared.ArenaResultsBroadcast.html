Remarks

The recipient's own team is not sent. It is in Placements already: every seat that receives this message is a seat that finished the match, and a finished seat has a row there carrying its character id and team. UITKArenaResults matches its own character id against those rows.

Neither is the return countdown. The server times it as Math.Max(3, ArenaTemplate.ResultsSeconds) — authored content the recipient already holds, reached through ArenaTemplateID in this same message — so the results screen reproduces the clamp rather than being told the answer. A template it cannot resolve falls back to the same 15 seconds the server uses when a match has no template.

No match id: nothing read it, and nothing sends this message back.
