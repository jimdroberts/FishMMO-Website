The decisions an arena match makes, as pure functions: whether a format can be played in a scene, when a match is over and who won, how players place, what a result does to a rank, and what an interaction with an objective does.

Remarks

Kept free of network, database and Unity state so each rule is a truth table that can be tested without a server. The match coordinator calls these; nothing here decides anything on its own clock.

ResolveControlPointInteraction(int, int, int, int, int)

What interacting with a control point does for one player.

public static ArenaControlPointResult ResolveControlPointInteraction(int ownerTeam, int progressTeam, int progress, int actorTeam, int interactionsToCapture)

Parameters

Current owner, or -1 for neutral.

Team whose capture is in progress, or -1.

Interactions accumulated by that team.

The interacting player's team, or -1 when not seated.

Interactions needed to take the point.

Returns

ArenaControlPointResult

Remarks

A team that already owns the point gains nothing by touching it. Another team's touch advances their own progress; a third team's touch, or a touch by a team other than the one in progress, restarts progress for the toucher's team — contesting is a race, not a tug of war. Reaching the count flips ownership and clears progress.

ResolveOutcome(IReadOnlyList<int>, int, bool, int, out int)

Decides whether a live match has ended, and who won.

public static bool ResolveOutcome(IReadOnlyList<int> teamScores, int scoreLimit, bool timeUp, int teamsWithPlayers, out int winnerTeam)

Parameters

teamScores IReadOnlyList<int>

Score per team.

scoreLimit int

Score that ends it at once, or 0 for none.

timeUp bool

Whether the clock has run out.

teamsWithPlayers int

How many teams still have at least one player in the match.

winnerTeam int

Winning team index, or -1 for a draw or an undecided match.

Returns

bool

True when the match is over.

Remarks

A team reaching the limit wins immediately. Time running out gives the match to the highest score, or draws it. A match with only one team left standing — everybody else left or was removed — ends at once in that team's favour, because there is nobody left to score against.
