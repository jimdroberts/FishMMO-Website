Remarks

The arena counterpart of DungeonTemplate. Referenced by an arena board so the board's panel can describe the arena, and by the match row so the scene server that hosts the instance — not necessarily the one that formed the match — can read the rules.

Team spawn points are ordinary CharacterRespawnPosition objects in the scene whose names start with the team's prefix, e.g. Team1_A. A team without any is spawned at the scene's respawn points at random, which is wrong for an arena but not fatal.
