AddAttributeRange(TooltipContent, string, ItemAttributeTemplate, int, bool)

Writes an attribute the item grants, as the range it can roll.

protected static void AddAttributeRange(TooltipContent content, string label, ItemAttributeTemplate attribute, int priority, bool describingInstance = false)

Parameters

content TooltipContent

The content being assembled.

label string

What the attribute is called on this item.

attribute ItemAttributeTemplate

The attribute template, or null.

priority int

Where the row sorts.

describingInstance bool

Remarks

A template describes what an item of this kind CAN be, not what one particular item is: the value is rolled per instance by ItemGenerator, which writes the rolled number itself. A single number here would be a promise the item does not keep.

BuildTooltip(TooltipContent, bool)

Describes the item, either as a kind of thing or as one the player is holding.

public virtual void BuildTooltip(TooltipContent content, bool describingInstance)

Parameters

content TooltipContent

The content being assembled.

describingInstance bool

True when an instance's own rolled values follow.

Remarks

The distinction matters for anything that rolls. A template can only say what an item of this kind CAN be — "Attack Power 1 - 3" — while an instance knows what it rolled, and ItemGenerator writes that. Printing both put the range and the roll in the same tooltip under two different names, which reads as two separate bonuses.
