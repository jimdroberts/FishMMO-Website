A climate reading a biome can be experienced under: the same Forest, frozen or scorched.

Biomes are fixed when the world is generated; what the current climate changes is the variant — and with it the names a place is given and, for the terrain painter, the textures it wears. A template lists its own variants; one that lists none takes the defaults from the scene's ClimateSettings.
