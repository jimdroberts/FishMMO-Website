Class SceneBiomeMap

Namespace
FishMMO.Shared.Biomes
Assembly
FishMMO.Shared.dll

Which biome lies where in a scene, baked when the world was generated: a grid of BiomeTemplate IDs over a rectangle of world space. Imported from the biome-map cells WorldEditor exports, or painted by any other tool; both the server and the client read it, so it holds IDs rather than a texture.
