What the run-time cave cover reads of a cave's rock (2026-11-03), baked at the cut beside its pieces in the scene's caves asset and named on its CaveCoverSite: per piece, its vertices cut down to the four attributes FishCaveCover.compute reads (position, normal, colour, TEXCOORD3, each in the piece's own format, so the cover lands bit for bit where the mesh would put it) and its first submesh's indices.

Remarks

The stored pieces are unreadable (CaveShaper): a player uploads them straight to the GPU with no CPU copy, and there re-targeting a piece's index buffer raw for the compute fails ("index buffer is null"), so no cover ever grew in a player. The cover reads this instead, in buffers of its own. About half the render vertex (36 of 68 bytes); the pieces stay unreadable, and a server never loads it (the Visual is client-only).
