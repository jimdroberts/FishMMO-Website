Namespace FishMMO.Shared.Celestial

Classes

LocalWorldClock

The world's tick when there is no server: a stand-in for FishNet's synchronised tick that the World Sim bed (or any offline tool) runs, and drives the shared WorldClock exactly as a scene server does — so everything in the editor reads time down the same path as the game.

WorldClock

World time, carried forward by FishNet's synchronised tick and anchored to one reference clock.

WorldClockPreview

A preview holding the world clock (test scenes and editor previews; never on a server), in place of the shared clock.

WorldEpoch

The real instant the world clock counts from (Unix seconds, UTC): world seconds are seconds since it.

WorldMotion

The clock the world's own motion runs on: the sea's waves, the surf on a beach, rain and snow falling, the trees in the wind, the fog banks, the fish.

WorldTime

The world time, in real hours since the calendar epoch, from wherever it is known.

WorldTimeText

The world time written as text, to the millisecond: what an admin types to set the clock, and what every readout shows. One form for the in-game commands, the Control Panel and the editor.

WorldClockAnchor

"At server tick Tick, world time was WorldSeconds, and it runs at Rate world seconds to each second of ticks."

WorldMotion.HeldValue

A value held still for each window of the motion clock (Window(double, out long)): taken when the window begins, or when this client first sees the window (a join part-way through).
