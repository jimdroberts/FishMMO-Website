Remarks

Declared with [assembly: CharacterPart(typeof(MyPart), typeof(IPlayerCharacter))]: every character that is (or derives from, or implements) the second type gets one, on every peer, in BaseCharacter.Awake before the character's behaviours are initialised, so it is found by TryGet<T>(out T) like any behaviour.

It is not a NetworkBehaviour: it talks over broadcasts, and its spawn-time state rides the character's own spawn payload (WritePayload(NetworkConnection, Writer), framed by part, so a reader skips a part it does not have). The character forwards its lifecycle: OnStartServer(), OnStopServer(), ResetState(bool) (pooling), and OnStartCharacter()/OnStopCharacter() on the client as for every behaviour.
