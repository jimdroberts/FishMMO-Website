Remarks

The tick fields start at zero, meaning "never": no gap pending, no refill yet. Each side keeps them on its own clock (the server on its monotonic clock, the client on the wall clock), so a starting value taken from either clock would be wrong for the other: a wall-clock stamp read by the server's monotonic gate refused every line.

Server: UTC ticks until which the player's chat is muted: 0 when not muted, long.MaxValue for a mute with no end. Never written to the spawn payload.
