Namespace

A character's standing toward others, as the rest of the game asks it: alliance level and its colour, the aggression toggle and its lock, setting a standing by template id. Core: implemented by the Factions module's FactionController (a character part); without the module a character has none and every caller treats that as "no relation" (the harm rule allows, AI sees no enemy but the aggressive).

GetStandingAllianceLevel(IFactionController)

The standing between the two as it is, without the aggression toggle: GetAllianceLevel(IFactionController) reads any pair where either side's aggression is on as Enemy (so hostile effects reach neutrals), and that widening is for HOSTILE reach only. Beneficial targeting (a heal or cleanse that reaches neutral players) reads this, so turning aggression on does not stop a player healing the neutral player beside them.
