Remarks

Discovery is server-authoritative. The server unlocks a waypoint when the character interacts with it (or a designer grants it), persists the unlock, and tells the owner; the owner's copy exists so the world map can draw what it knows without asking. Nothing the client holds here is trusted for anything — a fast-travel request is re-checked against the server's copy.

The static events are the seams the rest of the game hangs off: the server's interactable system persists and broadcasts on OnWaypointUnlocked, the client map redraws on it, and the UI plays its sounds on the travel events. They are static because the controller lives on the character and the systems that care outlive any character.

Remarks

The bits are OR-ed into the confirmed set rather than replacing it. The database write is itself an OR-merge, so any bit that was written is durable regardless of what else was unlocked while the write was in flight — those later bits stay dirty on their own and go out with the next save. No version counter is needed for that; the mask is its own version.
