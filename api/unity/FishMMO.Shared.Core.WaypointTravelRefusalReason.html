Why a fast-travel request was declined. Sent to the owner so the map can say so rather than appear to ignore the click.

public enum WaypointTravelRefusalReason : byte

Fields

CannotAct = 1

The character is dead, incapacitated, mid-transfer or not yet loaded.

ConditionsNotMet = 6

The waypoint's designer-authored travel conditions were not met.

InCombat = 2

The character is in combat. Fast travel is never a combat escape.

Locked = 5

The character has not discovered the waypoint.

None = 0

Not refused.

NotAuthoritative = 8

The peer asked to travel is not the authority. Only ever seen in a misconfigured process.

NotInScene = 4

The request named a scene other than the one the character is standing in. Waypoints are usable only from inside their own scene until the world-map system lands.

TooSoon = 7

The character travelled too recently.

UnknownWaypoint = 3

The waypoint named by the request does not exist in the scene the character is in.

Remarks

Ordered from "the player cannot do anything right now" to "this particular waypoint is not available", which is also the order the server checks them in. See WaypointTravel.Decide for the truth table.
