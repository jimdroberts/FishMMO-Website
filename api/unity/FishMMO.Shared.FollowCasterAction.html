Remarks

Wire it to the ability's OnTick, with Speed 0 and no move action: this IS the object's motion. The object's sweep runs after the tick events, from where it was to where this put it, so everything the caster rushes through is swept and lag compensated like any projectile's path.

With EndWithCasterRush the object ends when the caster's rush does (it struck something, or ran its length), on the peers that resolve hits; a peer that only watches lets its copy run out its lifetime, which changes nothing because it applies nothing. A caster with no motor (an NPC) never rushes, so its object simply lives out its lifetime in front of it.
