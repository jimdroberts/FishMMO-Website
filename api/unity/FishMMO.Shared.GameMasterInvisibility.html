Server-side set of characters hidden by /gm invis. A hidden character is not observed by any connection except its own and staff (game masters and above), so it is despawned on every other client: no model, nameplate, sound or broadcast reaches them.

Remarks

Enforced by ObserverBudgetCondition, one of the scene server's default observer conditions, so it covers every character without a per-prefab condition. Staff keep seeing a hidden colleague so two game masters working the same scene do not lose each other.

Keyed by the object, and cleared when the character despawns (the caller's job): characters are pooled, and a pooled object reused by another player must not arrive hidden. Not persisted: a game master who relogs is visible again.
