IL-embedded host configuration.

The defaults here are sentinels, and this file is tracked so the project always compiles. The real values live in the gitignored HostConfig.generated.cs, written by FishMMO Dashboard > Game Settings (or by CI substituting the sentinels in GeneratedFileTemplates/HostConfig.generated.cs.template), which implements FishMMO.Shared.HostConfig.Configure(FishMMO.Shared.HostConfig.Values) to overwrite them.

Why the split: a fresh clone has no generated file. When the generated file declared the whole class, its absence was a compile error, and a project that fails to compile on first open drops into Safe Mode, where no editor code runs — including the FishMMO menu that writes the file. An unimplemented partial method is removed by the compiler, so a missing generated file now just means sentinels, which ClientSecurityBuildValidator refuses to ship.
