A static, canonical Huffman code over bytes, for compressing whole network packets with a table both peers already hold (no table on the wire). Every byte value has a code, so any packet can be encoded; codes are at most MaximumCodeLength bits, so decoding is one table lookup per byte.

Remarks

Bits are written least significant first (as DEFLATE does), with each code stored bit-reversed so the decoder can index its table with the next MaximumCodeLength bits directly. The code is defined entirely by the 256 code lengths (Lengths), which is what a trained table stores.
