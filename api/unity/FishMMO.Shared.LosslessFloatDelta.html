Exact delta encoding for floats: each changed component travels as the difference between the two values' IEEE-754 bit patterns, zigzag varint packed. The reader adds it back to the baseline's bits, so the decoded value is the written one BIT FOR BIT.

Remarks

Why not FishNet's vector deltas. They round each difference to 1 mm (a quaternion's to 1e-4) and do not send a smaller one at all, so a delta reconcile restored the owner up to a couple of millimetres from the server's state. The motor then replayed from a state the server never had, and any threshold a millimetre can cross (the 5 mm ground probe on unstable ground, a climb's arrival and top checks) could decide differently on the replay than on the server, which shows as a correction.

Cost. A difference of N units in the last place packs to about log128(2N) bytes: a few metres from the baseline at a few hundred metres out is 3 bytes an axis, about one more than the rounded form. A component that crosses zero costs up to 5 bytes for that one write, because sign and magnitude are separate in the bit pattern. Unchanged components cost nothing beyond a 3- or 4-bit mask.
