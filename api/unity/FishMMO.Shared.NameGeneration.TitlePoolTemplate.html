Class TitlePoolTemplate

Namespace
FishMMO.Shared.NameGeneration
Assembly
FishMMO.Shared.dll

Titles and places shared by every race in one or more categories, drawn on top of each race's own Titles. A pool for "Undead" gives every undead race grave-wardens and barrow-lords without repeating them on each template; a pool with no categories serves every race. Registered in TitlePoolRegistry on load.
