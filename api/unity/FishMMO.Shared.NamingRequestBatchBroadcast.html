Remarks

One per kind per frame, replacing one NamingBroadcast per ID. Opening a 100-member roster sent 100 requests in one frame, each answered by a query of its own (hot-path audit M18); the IDs now travel together and the server resolves the ones it does not already hold in one query. The server answers with NamingBatchBroadcast.

Added alongside NamingBroadcast, not in place of it: the server still answers the single request, and answers each waiting connection in the form it asked in.

A parallel primitive array, not an array of entries: FishNet's codegen writes arrays of primitives itself, and a custom element type would need a hand-written array serializer.
