Remarks

Why a static code. Game packets are small (tens to a few hundred bytes): a general compressor has no history to work with inside one, and a shared adaptive model cannot survive unreliable, unordered delivery. A fixed code both peers already hold needs neither: each packet is compressed on its own, with nothing on the wire but its bits.

Wire format. One header byte: RawPacket followed by the packet unchanged, or HuffmanPacket followed by the packet's length (a 7-bit varint) and its code bits. The sender takes whichever is shorter, so a packet never grows by more than MaximumGrowth.

Switched on by the tables. Installed only when both trained tables exist, and then on every peer of the same build (client, login, world and scene servers), so the two ends always agree. Until a table has been trained from a sample (the simulate report's compression lines), nothing is installed and the wire is unchanged.
