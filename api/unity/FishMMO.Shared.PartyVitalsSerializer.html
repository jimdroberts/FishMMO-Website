Remarks

Hand written so the buff array is written only when BuffsChanged is set — a generated writer would put a length prefix on the wire for every member every time — and so the EditMode tests can round-trip the payload without the IL weaver. ObservedBuffEntry is written field by field here for the same reason; its layout is four fields and is not expected to change without this file changing with it.
