Remarks

The summon counterpart of the base template's On Hit / On Spawn lists, which a summon never runs (IsCompatibleWith(AbilityTemplate)). Bundled effects run on every summon by this spell, and their PetAbilities join PetAbilities.

PetAbilities

Abilities the summoned pet starts knowing.

[Tooltip("Abilities the summoned pet starts with. Learned on summon and persisted.")]
public List<AbilityTemplate> PetAbilities

Field Value

List<AbilityTemplate>

Remarks

These are taught to the pet's IAbilityController on summon and persisted with it, so the pet keeps them across a log out. The pet prefab's own Abilities list is learned as well; use that for abilities every pet of this species has, and this list for abilities granted by the summoning spell.

BuildPetAbilityIDs(Ability, List<int>)

The ability template IDs a pet summoned by this spell is taught.

public List<int> BuildPetAbilityIDs(Ability summoningAbility, List<int> persisted)

Parameters

summoningAbility Ability

The cast that summoned the pet, or null on a restore.

persisted List<int>

Ability template IDs restored from the database, or null on a fresh summon.

Returns

List<int>

A new list of ability template IDs, never null.

Remarks

The persisted list first (a pet restored at login keeps everything it was saved with, including abilities a crafted effect granted), then this spell's own PetAbilities, then what each summon effect teaches. Duplicates and abilities a pet cannot be taught are skipped.

The summon effects come from summoningAbility when there is one, because that is the ability as the player crafted it: it holds this template's bundled effects and the crafted ones. A restore has no cast, so it reads the bundled effects from the template; the crafted grants it needs are already in the persisted list.
