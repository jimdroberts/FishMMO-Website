Events

OnOwnerAttacked

Raised on the server when this controller's owner is damaged by a hostile character.

public event Action<IPetController, ICharacter> OnOwnerAttacked

Event Type

Action<IPetController, ICharacter>

Remarks

A defensive pet has to know its owner is under attack, and the owner is a player with no aggression table of its own to read. Subscribing here — one handler per player, mirroring what AggressionState already does per NPC — is what lets a defensive pet come to its owner's aid instead of watching.
