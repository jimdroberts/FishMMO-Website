Remarks

A kind IS a POIType, so the name generator, the generated scene data and the map all speak of the same thing. Each kind has its own MapMarkerType of the same name (2026-10-10), found by name so the two enums can never drift apart silently: a kind with no marker type answers Landmark, and a unit test pins that none does.
