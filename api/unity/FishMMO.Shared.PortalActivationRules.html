Remarks

Unknown is not closed. A server that has not yet read a character's (or a scene's) activations from the database answers null for "is it open", and the verdict for that is NotReady, a refusal that changes nothing. Treating it as closed would let a player who already opened a portal open it again, and a portal that spends its key would take a second key for it.

Requirements are any-of. One passing condition opens the portal; the key is one more alternative, tried after the conditions so a player who qualifies some other way keeps the key. A portal with no conditions and no key opens for the first player who uses it — a generated portal ships that way until a designer assigns its requirements.
