Remarks

Keyed by handle, like WaypointRegistry, because instances load several copies of one scene into one process. Portals register in OnEnable on every peer — a SceneTeleporter portal has no NetworkObject and so no server start to hang it on — and the server uses the registry to know which scenes' world rows to read and which portals to report to a player entering a scene.
