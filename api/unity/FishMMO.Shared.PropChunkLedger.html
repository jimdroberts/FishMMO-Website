Which of one scene's prop collision chunks are wanted, kept by reference count: every focus point holds the chunks round the 32 m cell it stands in, and a chunk is wanted while any focus holds it. The bookkeeping half of PropColliderStreamer, with no Unity objects in it, so it is testable on its own.

Remarks

By cell, not by point. A focus is placed again only when it crosses into another cell (or its radius changes), and then holds every chunk within its radius of ANY point of that cell (CellGap(int, int, float)). That is a superset of the chunks within its radius of where it actually stands (PointGap(Vector3, int, int, float)), for every point in the cell, so moving inside a cell never needs a chunk the focus does not already hold.

Released late. A held chunk is let go only once it is more than the radius and the release margin from the focus's cell, so a focus pacing across a cell edge does not empty and rebuild the chunks along the far rim each time. It only ever keeps more collision, never less.
