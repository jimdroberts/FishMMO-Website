Remarks

Keyed by scene, as WaterQuery is: a scene server runs several world scenes, and stacked instances of one, at once, each in its own physics scene. A character asks with its own scene, so it only ever finds the ladders of the world it stands in.

A climbable is its index in its scene's list. Server and client load the same asset, so the index means the same climbable on both, and it is what the reconcile carries (as index + 1; zero for none). The scene's handle differs between the peers and never goes on the wire.
