Class SceneGlowCaves

Namespace

FishMMO.Shared.dll

The linked caves' boxes the glow modes read (pure; the GPU's FishGlowCaveRow mirrors RowAt(IReadOnlyList<SceneGlowCave>, Vector3, int)): found from the cave-life spots every client loads (SceneCaveLife: each spot of a linked cave carries its interior biome), so nothing new is stored. A glow whose origin is inside a box reads the box's row before any anchor disc or the biome grid.
