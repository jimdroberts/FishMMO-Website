DeriveSeed(SceneObjectNamingSettings, string)

The seed a name is generated from. With a region seed it is a stable hash of region + object, so the same object gets the same name on every server start; otherwise it is a fresh draw per spawn. Never zero — zero is the wire's "no generated name" sentinel.

ResolveGender(NamingGenderPolicy, RaceTemplate, DeterministicRNG)

Picks the gender for a name under the given policy. RaceModels draws only among genders the race actually has models for, so a male-only race never receives a feminine name; a race with no gendered sets falls back to a coin flip.
