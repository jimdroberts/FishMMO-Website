Remarks

In play, read through each set's cell index (SceneSiteEmitters.EmitterIndex): only the cells within reach are looked at, and each emitter in them is measured exactly as before, so the result is the same set. Equal distances are ordered by set and emitter, where the old sort left them in no particular order.
