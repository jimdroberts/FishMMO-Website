Class SceneTerrainBake

Namespace
FishMMO.Shared
Assembly
FishMMO.Shared.dll

Holds a scene's TerrainDetailBake on a client-only object at its root (ObjectName), and lists every loaded scene's while enabled, so the client's grass and detail scatter can find a terrain's baked maps (TileOf(TerrainData, out TerrainDetailBake)), the array terrain its stored index map (IndexOf(TerrainData)), and the grass a texture set's colour copy (AlbedoOf(Texture2DArray)).

Remarks

Under a ClientOnlyObject, so server builds drop it and the bake with it. The editor never enables it (it is not an edit-mode script): the bake is only looked up in play.

IndexOf(TerrainData)

The stored index map of a terrain's data (TerrainDetailBake.IndexMap) in any loaded scene's bake, when it may be drawn on that data (UsableFor(TerrainData)); null otherwise. Play only (the holder registers in play). Independent of the bake's Version and of the tile's own staleness, which are the grass's and the scatter's.

Remarks

A holder whose OnEnable has not run yet (a binder binding from its own OnEnable while the scene loads) is found among the loaded objects instead, so the first push of a scene already sees its maps.
