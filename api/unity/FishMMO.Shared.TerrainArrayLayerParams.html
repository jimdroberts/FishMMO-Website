Remarks

A plain value rather than a UnityEngine.TerrainLayer because the layer whose numbers the ground draws with is not always one a scene may reference: when LOCAL art overrides a layer, its tiling and remaps come from an asset under Assets/LOCAL. These values are therefore copied into the baked TerrainArraySet (build output) and never into the scene.

The packing mirrors what Unity's terrain engine hands URP's TerrainLit, so a layer looks the same in both shaders: the diffuse remap's maximum is a tint (URP ignores the minimum), the mask remap becomes an offset (the minimum) and a scale (maximum minus minimum), and a layer whose albedo carries smoothness in its alpha uses a smoothness multiplier of one.

Remarks

  • st: 1/tile size, offset/tile size — applied to WORLD x/z, so a texture runs straight across tile seams.
  • tint: diffuse remap max rgb, normal scale in w.
  • maskOffset, maskScale: the mask remap as sample * scale + offset.
  • surface: metallic, smoothness multiplier, has-mask flag, 0.

A tile size of zero or less would divide by zero; it is clamped to a millimetre, which shows as obvious noise rather than a NaN that blacks out the ground.
