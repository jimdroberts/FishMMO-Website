Class TerrainDetailBake.IndexMap

Namespace
FishMMO.Shared
Assembly
FishMMO.Shared.dll

One terrain's index map (TerrainIndexMap) as the cut stored it: every alphamap texel's four strongest layers and their weights, two words a texel, row by row — the CPU bake from the alphamaps the cut wrote, the GPU bake's texels bit for bit. A player binds it instead of baking from the alphamaps, so a client build can leave the alphamaps out (ClientTerrainLayerStripper, which checks the map against them first).
