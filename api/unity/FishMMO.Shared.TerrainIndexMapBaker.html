Remarks

From the GPU's alphamaps, because a terrain paint stroke writes them there first and synchronises the CPU copy only when the stroke ends: baking from them keeps painting live (the binder rebakes a tile on every alphamap change), as reading the alphamaps per pixel did. Each map is copied into one slice of a scratch array, and one full-screen triangle (FishTerrainIndexBake.shader) writes every texel's four strongest layers. A 512² tile of eight maps is eight copies and one small draw; nothing is read back.

Baked live while the ground is edited, stored for play (2026-10-16: "store index maps with the terrain at cut/repaint, still re-baked live while painting in the editor"). In edit mode every tile is baked here from its alphamaps, on every change. The cut also stores each tile's map, baked on the CPU by the same rule (Bake(float[,,])), in the scene's TerrainDetailBake; in play (the editor's and a player's) the binder uploads that (Upload(IndexMap, string, Shader)) when it is still the alphamaps' own, and bakes here only when it is not. A client build then leaves the alphamaps out of every tile whose stored map it has checked against them (ClientTerrainLayerStripper), and the CPU readers that used them (GroundColourMap, the grass's surface layers) read the stored map on such a tile.

Integer arithmetic on bytes, so the GPU bake is BakeTexel(byte[], int, int, out uint, out uint) exactly; the editor checks a sample of texels against it once per tile and session (Check(Terrain, RenderTexture, int, int)).

Upload(IndexMap, string, Shader)

Reconstructs stored words in an integer render target from two RGBA8 staging texels per index texel. This uses the same representation as live painting, avoiding integer Texture2D creation and its different capability rules. The temporary source has no mipmaps, sRGB conversion or filtering; the upload pass rounds bytes before packing. The caller owns the target. Stored CPU words and the final eight bytes per texel are unchanged.

public static RenderTexture Upload(TerrainDetailBake.IndexMap stored, string name, Shader shader = null)
