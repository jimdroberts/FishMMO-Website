Remarks

Why a texture. At 256 layers the six arrays and the three path tables would be 27 KB of constants, pushed per terrain tile through its property block — more than the 16 KB uniform block OpenGL ES and WebGL guarantee, and exactly the pattern that broke the grass on OpenGL (large constant arrays varied per draw: unity-gl-indirect-args-barrier-bug). A structured buffer is not readable in a WebGL 2 fragment shader. A texture is one binding everywhere, read with Load (no sampler, exact floats).

Rows, Width columns each (Pack(int, Vector4[], Vector4[], Vector4[], Vector4[], Vector4[]) for the first five):

  • RowST: 1 / tile size and offset / tile size, applied to world x/z.
  • RowTint: the diffuse remap maximum (a tint), normal scale in w.
  • RowMaskOffset, RowMaskScale: the mask remap as sample × scale + offset.
  • RowSurface: metallic, smoothness multiplier, has-mask flag.
  • RowFlora: what the layer is made of for the planet's looks (LayerFlora()).
  • RowPaths: the slices of the layer's own biome's path ground, road ground and cobbles (−1 none).
  • RowBackdrop: not a layer's but a backdrop channel's: the scene layer channel c of the backdrop's control maps holds (ControlLayers), c itself when the backdrop names none.
  • RowGlow: the layer's glow (2026-10-25, phase I2r; Biomes.BiomeGroundGlow.Pack), zero for none.
  • RowClock: how the layer follows the shared clock (2026-10-26, phase GROUND-BANDS; Biomes.BiomeGroundClock.Pack): x kind, y from, z to, w falloff; zero for none.
  • RowClockShare: x the share a clocked layer keeps outside its window, y the layer that takes the rest (−1 none), w 1 in every column when any layer of the scene follows a clock (the shader's one test before it reads more).

Columns past the scene's layers hold a neutral layer, no flora and no paths, as the arrays' unused slots did.
