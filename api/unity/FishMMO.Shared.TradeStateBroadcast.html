Remarks

The full state every time rather than deltas. A table holds at most a handful of items, so the saving would be small, and a client that has missed nothing still repaints from scratch — which is also what makes it trivially correct after a tree rebuild.

Receiver-shaped: the same change produces two different messages, one per party, each saying "own" and "partner" from that party's point of view. Neither client has to know which side of the session it is.
