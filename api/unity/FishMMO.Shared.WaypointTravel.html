Remarks

One routine for every caller — the map request handler and the ECA teleport action — so the rules cannot drift between them. The rules themselves are in Decide(bool, bool, bool, bool, bool, in WaypointTravelOptions), a pure function over the answers, so the truth table is testable without a scene.

Server only. The position write is the same primitive respawn and cross-scene arrival use (KinematicCharacterMotor.SetPositionAndRotationAndVelocity); the owner's client learns of it through the next reconcile, exactly as it does for a respawn.
