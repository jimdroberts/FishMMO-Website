Remarks

It reads levels, never other recipes. A recipe's ingredients are always WeatherExposureTemplate levels, so the whole set can be evaluated in one pass with no ordering to get right and no way to write a cycle. Two recipes can name the same ingredient, and both hold.

Nothing of it rides the wire. A recipe is a pure function of the levels, and the levels already reconcile — so both peers reach the same verdict from the same numbers, and the reconcile payload does not grow by a byte for any number of recipes. What is NOT derivable is which side of the hysteresis band a recipe was on, and that is re-derived after a reconcile exactly the way a single state's hold is: see WeatherExposureController.

Static content only. Like every template, this holds no runtime state; which recipes a given character currently satisfies lives on that character's controller.

Remarks

Two thresholds, as everywhere else in exposure: a recipe that is not currently held needs every ingredient at its AtLeast, while one that IS held only lets go once an ingredient drops ReleaseMargin below it. Without the gap, a character standing in weather that parks an ingredient exactly on its threshold would gain and lose the combined buff on alternate ticks.
