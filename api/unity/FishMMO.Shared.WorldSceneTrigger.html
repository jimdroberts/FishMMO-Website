Inline ECA trigger data for world-scene events (scene load, day start, night start, …).

Unlike the asset-based Trigger, this type is [Serializable] and lives directly on a host MonoBehaviour so designers can author scene-specific responses inline. Execution semantics — selector fan-out, condition branching, action dispatch — are delegated to RunInline(TargetSelector, List<BaseCondition>, List<BaseAction>, List<BaseAction>, EventData) so this type stays in lock-step with any future Trigger behaviour changes.
