Remarks

These are policies over the existing four AccessLevel values plus a step-up window, deliberately not a fifth access level: the enum is duplicated between FishMMO.Auth.Core and the database layer and is baked into the wire format and the in-game commands, so the panel expresses finer distinctions without touching it.

Remarks

Moderation sits here rather than at Operator: banning an account is a game master's daily work, and requiring an administrator for it means the person handling the report cannot act. The step-up is what makes that safe — a borrowed unlocked session cannot ban anybody without the authenticator.
