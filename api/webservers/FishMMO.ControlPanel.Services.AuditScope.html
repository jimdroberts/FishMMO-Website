Remarks

AuditActionFilter fills this in from the route and the bound arguments before the action runs, and writes it afterwards. An action that knows something the filter cannot — the name a character had before it was renamed, or which fields an edit actually changed — assigns to it in one line. An action that knows nothing extra assigns nothing and is still recorded.

Scoped per request. It is the reason no controller needs to call an audit method, which is the reason no controller can forget to.
