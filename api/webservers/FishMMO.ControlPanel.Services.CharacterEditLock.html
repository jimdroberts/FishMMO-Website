Remarks

A live character's row is not authoritative. Its state lives in the owning scene server's memory, and the persistence pass writes that memory over the row — name included. So an edit made here while a server holds the lease is not merely racy, it is reliably lost on the next save.

The lease is the test, not the online flag: a server that crashed leaves session_state = Online behind, and waiting for that to be cleaned up by hand would lock the character out of the editor forever. An expired lease is no lease.
