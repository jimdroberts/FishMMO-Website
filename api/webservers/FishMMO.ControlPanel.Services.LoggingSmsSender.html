Remarks

No SMS gateway exists in this project yet. This sender is what lets the phone verification flow be exercised end to end on a development machine: the code shows up in the panel's log. It logs the body, which carries a verification code — acceptable here precisely because this is a development stand-in, and the reason it is not configured in Production unless an operator names it explicitly.

Configured when Sms:Provider is log, or — outside Production only — when no provider is named at all. In Production with no provider the drain logs once and idles, as the email drain does with no SMTP host, and queued messages wait for a real sender.
