AutoVerifyAccounts

Whether new accounts skip verification.

public bool AutoVerifyAccounts { get; init; }

Property Value

bool

Remarks

The panel's counterpart to AccountVerificationPolicy.IsAutoVerifyEnabled. Like that one it must never be reachable in production: it is honoured only outside the Production environment, so a development configuration file that reaches a production host cannot re-enable the bypass. A server whose VerificationOptions turn every channel off reaches the same auto-verify path by a different, production-legal road.

ExposeResetCodes

Whether a password reset returns the emailed code in the response body.

public bool ExposeResetCodes { get; init; }

Property Value

bool

Remarks

A development affordance, and the same shape as AutoVerifyAccounts: with no mail sender running there is no way to exercise the recovery flow locally at all.

It is honoured only outside the Production environment, and PasswordResetService checks the environment itself rather than trusting this flag alone — so a development configuration that reaches a production host cannot re-enable it. The default is on because the environment check, not this switch, is what keeps it out of production.
