Core seams it uses

Seam What the module does

ClientWorldGUI_Panels label (ModulePanelHost) UIAbilityCraft.prefab is placed into the world GUI.
AbilityCrafterBroadcast (core) The window opens when a crafter's ECA action sends it.
Accomplishments.Record A crafter's achievement is credited on a successful craft.
[assembly: GameModule] AbilityCraftingModule ("abilitycrafting").

What stays in the core

Abilities: templates, events, learning, the grant funnel and prediction. The ability crafters placed in the world, their ECA action and the message it sends (AbilityCrafterBroadcast). The currency persistence and ledger helpers on ServerBehaviour.

Removing it

Delete Assets/FishMMO/Modules/AbilityCrafting (to check it, follow the gate). A crafter then opens nothing. No table belongs to the module.
