Remove together with Nothing
Moved Phase 3 of the core and modules plan, 2026-11-17. The plan grouped quests with achievements as "Objectives"; achievements stay in the core, because every system records accomplishments (Accomplishments.Record) and many core assets name an AchievementTemplate.

Core seams it uses

Seam What the module does
[assembly: CharacterPart] QuestController is added to every player at wake.
[assembly: CharacterPersistence] QuestPersistenceParticipant loads a player's quests; the quest system writes them when they change, not the character save.
SceneServer_Systems label QuestSystem.asset is adopted by the scene server.
IDashboardCategoryProvider QuestDashboardCategories.
[assembly: GameModule] QuestsModule ("quests").

What stays in the core

Achievements (AchievementTemplate, Accomplishments, the achievement system). The ECA framework the quest actions and conditions plug into.

Removing it

Delete Assets/FishMMO/Modules/Quests (to check it, follow the gate). There is no quest content yet (no templates, no quest givers placed), so nothing in the world changes. The character_quests table stays in place, unused.
