Staff and Support module

Short description: The staff tools and player support: the /gm and /admin command sets, the staff console, game master presence (fly, invisibility), and /report, /bug, /helpme, /tickets and the report window.
Module id staff (StaffModule)
Assemblies FishMMO.Staff, .Server, .Client, .Tests
Depends on The core
Depended on by None. Modules that add commands (Housing, World Simulation) do it through the core's OperatorCommandProvider, so they compile without this module; their commands are simply not reachable.
Remove together with Nothing
Moved Phase 3 of the core and modules plan, 2026-11-17. These were partials of SceneServerSystem and ChatSystem; they are one system now.

Core seams it uses

Seam What the module does
SceneServer_Systems label StaffSystem.asset is adopted by the scene server.
ClientWorldGUI_Panels label UIStaffConsole and UIReportPlayer prefabs are placed into the world GUI.
OperatorCommandProvider Hosts every provider's commands, its own and other modules'.
ChatSystem.OnSendSystemMessage The support commands answer through it.
CharacterSystem.OnDespawnCharacter A game master's presence state is dropped when the character despawns.
CharacterMenuEntries "Report" on character menus.
[assembly: GameModule] StaffModule ("staff").

What stays in the core

  • The operator command contracts other modules use: OperatorCommand, IOperatorCommandHost, OperatorCommandProvider, OperatorCommandParsing and StaffArgumentKind.
  • GameMasterInvisibility (observer streaming honours it).
  • What the tools act on, exposed read-only by SceneServerSystem: WorldClock, WorldSceneDetailsCache, ScheduledPlayerTicks, IdleIntervalPlayerTicks, and DescribeServerControl() (the lock and shutdown state as report lines). Locking and shutting down still run through the server-control rows and the Control Panel.

Removing it

Delete Assets/FishMMO/Modules/Staff (to check it, follow the gate). Nothing then hosts the command sets, so no /gm or /admin command from any module is reachable, and there is no console or report window. The /admin gold currency setting lives on StaffSystem.asset. The support ticket, report and audit tables stay in place, unused.
