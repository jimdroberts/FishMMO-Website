What stays in the core

The world contracts (WorldClock, WorldTick, WeatherQuery, WaterQuery, ShelterQuery, BiomeHabitatQuery, climbing), the core surface shaders and their neutral defaults, the terrain material shaders, weather exposure, the race and wildlife templates (biome affinity by id, habitat flags), the scene object namer, FogComposer, and the module render pass host (FishModulePassesFeature) on the three URP renderers.

Removing it

Delete the seven world modules: WorldSimulation, Water, Terrain, AmbientLife, Naming, WorldDesign and WorldTestBed (to check it, follow the gate). World scenes then have no sky, weather, clouds or fog: the camera clears to a plain sky colour (CoreSkyColour), the scene's own directional light lights it, and the weather reads calm everywhere. World scenes built with the module keep missing scripts that point into it; a core-only game uses scenes made without it, such as the Core Gate world (Tests/TestHarness/Editor/CoreGateSceneGenerator.cs).
