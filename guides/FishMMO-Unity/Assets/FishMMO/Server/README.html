Server

View this file on GitHub

Short description: FishMMO.Server, the Login, World and Scene servers. One assembly holds the server contracts (Core/) and their implementation (Implementation/); each server type is an Addressable scene that ServerLauncher loads.

It references FishMMO.Shared, FishMMO.Core, FishNet and the transport, and uses the precompiled database DLLs in Assets/Dependencies (FishMMO-DB.dll, EF Core, Npgsql). It references no module. Modules add server systems by Addressables label and character persistence by assembly attribute (see ../README.md).

Folders

Folder Holds
Core/ The contracts and engine-light pieces: IServer, ICoreServer, IServerBehaviour, IServerConfiguration and FileServerConfiguration (the .cfg reader), IngressGuard, MonotonicClock, RepeatingFaultLog, ShutdownCountdown, Collections, Authentication, and the login, world, kick and SMTP contracts.
Implementation/ The composition root (Server.cs), ServerLauncher, ServerBehaviour and its registry, authentication and account managers, runtime data, SMTP, kick requests.
Implementation/LoginServer/ Account creation, character create, character select, server select, the login server and the login queue.
Implementation/World/WorldServer/ The world server, world scene placement and its authentication.
Implementation/World/SceneServer/ The scene server's systems: scene server, character (load, save, persistence participants), inventory, interactables, chat, AI, spawners, pets, achievements, hotkeys, naming, scene channels, abilities, the clock, navigation, waypoints.

Builds

Build the servers through FishMMO Dashboard → Build. The dedicated server is a Linux IL2CPP player; the build keeps the database assemblies that EF Core creates by reflection (see Implementation/README.md). Each server reads its .cfg file from its working directory; the templates are in FishMMO-Setup/ at the repository root, and the main README documents their keys.
