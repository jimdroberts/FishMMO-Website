FishMMO

A modular, open-source MMO framework built on Unity 6.3 LTS, FishNet, QUIC/WebTransport, and PostgreSQL.

FishMMO is a complete multiplayer online game stack: a Unity client/server/shared codebase with a full prediction pipeline, transport-agnostic SRP-6a + TOTP authentication, a PostgreSQL data-access layer, QUIC-based networking, and the supporting web services, tooling, and bots needed to run and operate a persistent world. This site combines the generated API reference for every C# project in the monorepo with every design note and README written across it — all in one place, cross-linked back to the source on GitHub.

What's Inside

FishMMO is split into focused products that run independently and communicate over QUIC/HTTP. Each one ships with generated API docs, hand-written design notes, or both.

UN

Unity

Client, server, and shared game code (560+ C# files) — full prediction pipeline, modular character visuals, threat-based AI, ECA trigger system.

Docs · API · Source
AU

Auth

Transport-agnostic .NET authentication library: SRP-6a, X25519 ECDH, token auth, and TOTP two-factor authentication.

Docs · API · Source
DB

Database

PostgreSQL data-access layer using Entity Framework Core + Npgsql — 36+ tables, 38+ services.

Docs · API · Source
WT

Web Transport

C++ native library wrapping MsQuic (QUIC/HTTP3) — P/Invoked from C# as a FishNet transport plugin.

Docs · Source
IN

Installer

Cross-platform .NET 8 console tool that automates dependency installation.

Docs · API · Source
DE

Dependencies

Centralized NuGet dependency aggregator (54 packages, netstandard2.1) — copies DLLs to Unity.

Docs · Source
LG

Logger

Flexible logging library with file, email, and console backends.

Docs · API · Source
SU

Shared Utility

Pure C# utility library shared between client and server projects.

Docs · API · Source
HM

App Health Monitor

Daemon that monitors, auto-restarts, and health-checks server processes.

Docs · API · Source
WS

Web Servers

ASP.NET Core 8.0 web services — IPFetch, Patcher, and the WebGL static server.

Docs · API · Source
PA

Patcher

Client-side updater that applies versioned patch files.

Docs · API · Source
SE

Setup

Configuration templates — nginx.conf, server .cfg files, appsettings.json, deploy hooks.

Docs · Source
DC

Discord Bot

Discord bot bridging in-game chat with a Discord guild.

Docs · API · Source

CMS

ASP.NET Core CMS for launcher news, announcements, and web content.
