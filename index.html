FishMMO

A modular, open-source MMO framework built on Unity 6.3 LTS, FishNet, QUIC/WebTransport, and PostgreSQL.

FishMMO is a complete multiplayer online game stack: a Unity client/server/shared codebase with a full prediction pipeline, transport-agnostic SRP-6a + TOTP authentication, a PostgreSQL data-access layer, QUIC-based networking, and the supporting web services, tooling, and bots needed to run and operate a persistent world. This site combines the generated API reference for every C# project in the monorepo with every design note and README written across it, each cross-linked back to its source on GitHub.

Server Architecture

The server architecture uses three server types, all launched from a single GameServer executable with a command-line argument (LOGIN, WORLD, or SCENE):

  • LoginServer — account creation, SRP-6a authentication, character select, and TOTP 2FA.
  • WorldServer — world state, character routing, and scene server orchestration.
  • SceneServer — gameplay simulation for individual world scenes (chat, combat, inventory, guilds).
